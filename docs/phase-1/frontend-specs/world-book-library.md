# 前端页面 Spec：世界观库

## 1. 页面信息

- 页面组名称：世界观库
- 所属阶段：第一期
- 目标用户：个人短剧创作者
- 关联模块 PRD：[世界观库](../module-prds/world-book-library.md)
- 页面路径：
  - 世界观列表页：`/world-books`
  - 新建世界观页：`/world-books/new`
  - 世界观详情编辑页：`/world-books/[id]`

## 2. 页面目标

世界观库用于创建、查看、编辑和管理可复用故事世界设定。世界观资产只保存跨项目稳定的时代背景、核心规则、组织、地点、社会结构、禁忌限制、风格约束和结构化条目；加载到项目后需要生成项目内快照，后续项目内修改不回写世界观库原始内容。

用户离开页面组时，应完成以下结果之一：

- 搜索或筛选已有世界观。
- 创建并保存一个世界观。
- 编辑世界观基础信息和核心设定。
- 新增、编辑、停用或启用世界观条目。
- 将世界观归档或设为可加载。
- 将 active 世界观加载到项目并生成项目内快照。

## 3. 用户流程

### 3.1 查看和筛选世界观

```text
进入世界观库列表页
 -> 查看世界观列表
 -> 输入世界观名称关键词或选择筛选条件
 -> 查看筛选后的世界观
 -> 点击世界观
 -> 进入世界观详情编辑页
```

### 3.2 创建世界观

```text
进入世界观库列表页
 -> 点击新建世界观
 -> 跳转到 /world-books/new
 -> 填写基础信息和核心设定
 -> 保存世界观
 -> 保存成功后跳转到 /world-books/[id]
```

### 3.3 维护世界观条目

```text
进入世界观详情编辑页
 -> 在条目区填写标题、类型、关键词、正文、适用范围和优先级
 -> 新增条目
 -> 编辑已有条目
 -> 停用不再参与加载的条目
 -> 保存后页面刷新条目列表
```

### 3.4 加载到项目

```text
进入世界观详情编辑页
 -> 确认世界观状态为 active
 -> 选择目标项目
 -> 系统检查目标项目是否已有项目世界观
 -> 点击加载到项目
 -> 系统复制世界观基础信息和 active 条目为项目内快照
 -> 页面展示加载成功提示
```

如果目标项目已加载世界观，页面应阻止继续加载第二个世界观，并提示用户先到项目工作台移除或替换当前项目世界观。

## 4. 信息架构

### 4.1 世界观列表页

- 页面标题区：世界观库、简短说明、新建世界观按钮。
- 筛选区：名称搜索、题材筛选、状态筛选。
- 列表区：世界观名称、题材、时代摘要、风格、条目数、状态、版本、更新时间。
- 状态反馈区：加载中、加载失败、空数据。
- 快捷操作区：进入详情、设为可加载、归档。

### 4.2 新建世界观页

- 页面标题区：新建世界观、返回列表入口。
- 基础信息区：名称、题材、摘要、状态。
- 核心设定区：时代背景、世界规则、组织、地点、社会结构、禁忌限制、整体风格。
- 操作区：取消、保存。
- 状态反馈区：字段校验、保存失败、未保存变更。

### 4.3 世界观详情编辑页

- 页面标题区：世界观名称、状态、版本、返回列表入口。
- 基础信息区。
- 核心设定区。
- 世界观条目区：新增条目表单和已有条目列表。
- 项目加载区。
- 信息区：创建时间、更新时间、条目数量。
- 危险操作区：归档世界观。

## 5. 布局结构

- 列表页使用 `.page-header`、`.panel`、`.filter-bar` 和 `.asset-list`。
- 新建页使用单列表单，表单宽度受 `.form-page` 控制。
- 详情页使用“主表单 + 侧栏”的 `.detail-layout`，主区域维护内容，侧栏承载项目加载和元信息。
- 条目列表使用卡片列表，每个条目提供编辑、启用/停用操作。
- 窄屏下双列布局降为单列，按钮组允许换行，不允许横向溢出。

## 6. 字段与控件

### 6.1 世界观字段

| 字段/控件 | 类型 | 是否必填 | 默认值 | 校验/约束 | 说明 |
| --- | --- | --- | --- | --- | --- |
| 世界观名称 | 文本输入 | 是 | 空 | 1 到 120 字 | 世界观主标识 |
| 题材类型 | 下拉或文本输入 | 是 | 都市情感 | 1 到 120 字 | 用于列表筛选和生成方向 |
| 时代背景 | 多行文本 | 否 | 空 | 建议不超过 3000 字 | 描述年代、地区、科技水平、社会环境 |
| 核心世界规则 | 多行文本 | 是 | 空 | 1 到 5000 字 | 生成内容必须遵守的规则 |
| 主要组织 | 多行文本 | 否 | 空 | 建议按行列出 | 组织、势力、公司、家族或机构 |
| 主要地点 | 多行文本 | 否 | 空 | 建议按行列出 | 城市、社区、公司、禁区或关键场景 |
| 社会结构 | 多行文本 | 否 | 空 | 建议不超过 3000 字 | 阶层、势力关系、资源分配方式 |
| 禁忌或限制 | 多行文本 | 否 | 空 | 建议不超过 3000 字 | 不可违反的设定、禁忌、边界 |
| 整体风格 | 多行文本 | 否 | 空 | 建议不超过 2000 字 | 叙事气质、视觉风格和对白风格约束 |
| 摘要 | 多行文本 | 否 | 空 | 建议 100 到 300 字 | 列表和加载预览展示 |
| 状态 | 下拉 | 是 | draft | draft、active、archived | 只有 active 可以加载到项目 |

### 6.2 世界观条目字段

| 字段/控件 | 类型 | 是否必填 | 默认值 | 校验/约束 | 说明 |
| --- | --- | --- | --- | --- | --- |
| 条目标题 | 文本输入 | 是 | 空 | 1 到 120 字 | 条目主标识 |
| 条目类型 | 下拉 | 是 | 世界规则 | 固定类型 | 世界规则、地点、组织、阶层关系、历史事件、特殊物品、禁忌或限制、风格约束、其他 |
| 关键词 | 文本输入 | 否 | 空 | 逗号或顿号分隔 | 后续用于上下文选择 |
| 条目正文 | 多行文本 | 是 | 空 | 1 到 5000 字 | 可引用的设定正文 |
| 适用范围 | 文本输入 | 否 | 全局 | 建议短文本 | 全局、特定角色、地点或剧情阶段 |
| 优先级 | 数字输入 | 是 | 0 | 整数 | 越大越优先 |
| 状态 | 下拉 | 是 | active | active、disabled | disabled 不参与项目加载快照 |

## 7. 交互与状态

- 初始状态：列表页自动加载世界观；新建页展示空表单；详情页加载世界观、条目和项目列表。
- 加载中：按钮禁用并展示加载文本。
- 未保存状态：新建和详情表单修改后展示提示；离开详情页前需要确认。
- 保存成功：更新版本、更新时间并展示成功提示。
- 保存失败：展示后端错误或通用中文错误。
- 归档确认：归档前必须弹出确认。
- 项目加载：有未保存修改、状态不是 active、未选择项目或目标项目已存在世界观时阻止加载。
- 条目停用：只改变条目状态，不硬删除。

## 8. API 依赖

接口合同、字段校验、状态/版本规则、条目启停和项目加载后端边界以后端接口 Spec 为准：[世界观库后端 Spec](../backend-specs/world-book-library.md)。本节只描述页面依赖关系。

| 行为 | 前端方法 | 后端接口 | 请求数据 | 响应数据 | 错误处理 |
| --- | --- | --- | --- | --- | --- |
| 查询世界观 | `listWorldBooks` | `GET /api/world-books` | search、genre、status | 世界观列表 | 展示列表加载失败 |
| 创建世界观 | `createWorldBook` | `POST /api/world-books` | 世界观字段 | 世界观详情 | 展示创建失败 |
| 查询详情 | `getWorldBook` | `GET /api/world-books/{id}` | id | 世界观详情 | 展示详情加载失败 |
| 更新世界观 | `updateWorldBook` | `PUT /api/world-books/{id}` | 世界观字段 | 世界观详情 | 展示保存失败 |
| 归档世界观 | `archiveWorldBook` | `POST /api/world-books/{id}/archive` | id | 世界观详情 | 展示归档失败 |
| 激活世界观 | `activateWorldBook` | `POST /api/world-books/{id}/activate` | id | 世界观详情 | 展示启用失败 |
| 查询条目 | `listWorldEntries` | `GET /api/world-books/{id}/entries` | id | 条目列表 | 展示条目加载失败 |

| 更新条目 | `updateWorldEntry` | `PUT /api/world-books/{id}/entries/{entryId}` | 条目字段 | 条目详情 | 展示保存失败 |
| 停用条目 | `disableWorldEntry` | `POST /api/world-books/{id}/entries/{entryId}/disable` | id、entryId | 条目详情 | 展示停用失败 |

## 9. 错误提示

- 世界观名称不能为空。
- 题材类型不能为空。
- 核心世界规则不能为空。
- 当前世界观有未保存修改，请先保存后再加载到项目。
- 只有可加载状态的世界观可以加入项目。
- 请先选择要加载到的项目。
- 该项目已加载世界观，每个项目只能加载一个世界观。请先在项目工作台移除或替换当前项目世界观。
- 条目标题不能为空。
- 条目正文不能为空。
- 世界观列表加载失败。
- 世界观详情加载失败。
- 世界观保存失败。
- 世界观加载失败。

## 10. 响应式要求

- 移动端下侧栏移动到主内容下方。
- 筛选条改为单列，按钮占满可用宽度。
- 条目卡片内长文本换行，不撑破容器。
- 表单 textarea 允许垂直拉伸。
- 按钮组允许换行并保持可点击区域稳定。

## 11. 验收标准

- 用户可以创建、查看、编辑世界观。
- 用户可以搜索和筛选世界观列表。
- 用户可以归档和激活世界观。
- 用户可以新增、编辑、启用、停用世界观条目。
- 用户只能将 active 世界观加载到项目。
- 每个项目最多只能加载一个世界观。
- 加载到项目后生成项目内快照，快照包含来源世界观 ID、来源版本和 active 条目。
- 项目内微调世界观快照不会修改世界观库原始内容。
- 前端页面与现有角色卡库视觉风格一致。
- TypeScript 检查通过。

## 12. 非目标

- 不实现世界观版本差异对比。
- 不实现世界观市场、模板商城或多人共享。
- 不在世界观库页面组内实现项目内世界观快照编辑；项目内微调入口由项目工作台承载。
- 不实现关键词自动触发算法。
