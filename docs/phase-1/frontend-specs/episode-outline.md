# 分集大纲与单集故事正文创作页面 Spec

## 1. 页面信息

- 页面名称：分集大纲与单集故事正文创作
- 页面路径：`/projects/[id]/story-text`
- 所属阶段：第一期，项目工作台 / 故事文本
- 关联 PRD：[分集大纲与单集故事正文创作](../module-prds/episode-outline.md)
- 关联功能设计：[项目工作台](../module-prds/project-workbench.md)
- 目标用户：个人短剧创作者

## 2. 页面目标

本页面帮助用户在“故事文本”入口内完成从整体故事大纲、分集大纲到单集故事正文的写作闭环。

用户进入页面时通常已经创建项目，并可能已经加载世界观、角色和整体故事大纲。用户离开页面时，应至少能够保存分集大纲或某一集单集故事正文。保存单集故事正文后，短剧制作应以该正文作为剧本、分镜、字幕和发布文案的主要输入。

AI 创作能力当前已接入“正文创作”：生成结果先持久化为候选稿，用户确认采用后才更新正式正文。续写、润色、撤销润色、摘要、一致性质检、角色参考、设定参考、文风和灵感面板仍保持后续入口。钩子提取和传播点沉淀归入短剧制作模块。

## 3. 用户流程

```text
进入故事文本页面
 -> 查看粘性子导航：故事大纲 / 分集大纲 / 单集故事正文
 -> 进入分集大纲，选择或编辑某一集大纲
 -> 进入单集故事正文
 -> 从左侧分集列表选择当前集
 -> 在中间编辑正文，在左中栏查看上游大纲参考、上一集正文摘要，并编辑正文摘要
 -> 查看右侧参考面板中的世界观、角色、设定、上一集正文摘要、文风和灵感入口
 -> 填写可选创作要求，生成并预览 AI 候选稿
 -> 编辑、采用或放弃候选稿
 -> 保存单集故事正文
 -> 返回短剧制作时，短剧制作读取该集正文作为上游输入
```

## 4. 信息架构

### 4.1 页面标题区

展示：

- 页面标题：故事文本。
- 当前项目名称。
- 返回工作台入口。
- 返回项目管理入口。

### 4.2 粘性子导航

展示当前故事文本模块内的子功能：

- 故事大纲。
- 分集大纲。
- 单集故事正文。

子导航高度应控制在单行，不使用大块卡片导航。

### 4.3 分集大纲区

展示：

- 分集列表。
- 当前集分集大纲表单。
- 当前集状态。

字段：

- 本集标题。
- 单集梗概。
- 开头钩子。
- 主要冲突。
- 关键反转。
- 结尾悬念。
- 预计时长。
- 状态。

### 4.4 单集故事正文工作台

采用结构优先的写作工作台布局，沿用当前浅色产品风格，不照搬参考界面的暗色视觉。

- 左侧分集列表：展示集数、标题、状态和当前集高亮，不展示本集梗概。卡片第一行左侧展示集数、右上角展示状态；标题独立放在第二行，避免与集数挤在同一行。
- 顶部模块导航空白区：在“单集故事正文”子功能下展示 AI 创作按钮组。
- 左中写作上下文区：上方只读展示上游大纲参考，包括分集标题、本集梗概、开场钩子、本集冲突、关键反转和结尾悬念；下方编辑正文摘要，并只读展示上一集正文摘要作为前文参考。
- 中间正文编辑区：作为最大视觉焦点，展示纸面化长文编辑器，并在标题栏展示字数、状态和保存按钮。
- 右侧参考面板：使用轻量 tabs 展示设定、角色、文风、灵感，并保留质检入口。

单集故事正文不是单集剧本。页面文案必须区分：

- 单集故事正文：可读故事 / 小说化文本。
- 单集剧本：短剧制作阶段的场景、动作、对白和旁白。

## 5. 布局结构

- 使用现有 app shell 和项目工作台页面结构。
- 页面标题区位于内容顶部。
- 子导航使用 `.module-subnav`，`position: sticky`，吸附在内容区顶部。
- 分集大纲区可使用两列布局：左侧分集列表，右侧大纲表单。
- 单集故事正文顶部工具栏中，故事文本内部导航和 AI 创作功能必须拆成两个独立区域：`.module-stage-switcher` 只负责「故事大纲 / 分集大纲 / 单集故事正文」切换，`.module-function-strip` 只负责 AI 功能按钮。
- 单集故事正文的 AI 创作按钮组不在左中栏单独占用卡片。
- 单集故事正文工作台在桌面端使用四区布局：
  - 分集列表：220-260px。
  - 写作上下文：280-320px。
  - 正文编辑区：自适应，占最大宽度，最小宽度不低于 440px。
  - 右侧参考面板：300-340px。
- 单集故事正文页不单独展示占据整行的标题区，当前功能名称由故事文本子导航高亮表达。
- 单集故事正文页不单独展示占据整行的工具栏；字数、状态和保存按钮合并到正文编辑区标题栏。
- 第一期不要求移动端专门适配，四区布局优先保证桌面端信息密度和编辑效率。
- 正文编辑区弱化普通表单感，使用白色纸面区域、更高编辑高度和适合长文阅读的行距。
- 摘要、钩子、关键节拍、前文上下文、质检备注不放在正文下方挤压正文，应放入左中上下文区或右侧参考区。

## 6. 字段与控件

### 6.1 分集大纲字段

| 字段/控件 | 类型 | 是否必填 | 默认值 | 校验/约束 | 说明 |
| --- | --- | --- | --- | --- | --- |
| 集数 | 只读文本 | 是 | 当前集 | 必须在项目集数范围内 | 由项目集数决定 |
| 本集标题 | 文本输入 | 否 | 空 | 最长 120 字 | 用于分集列表和正文标题参考 |
| 单集梗概 | 多行文本 | 否 | 空 | 最长 5000 字 | 描述本集主要剧情 |
| 开头钩子 | 多行文本 | 否 | 空 | 最长 2000 字 | 描述开篇吸引点 |
| 主要冲突 | 多行文本 | 否 | 空 | 最长 3000 字 | 描述本集冲突 |
| 关键反转 | 多行文本 | 否 | 空 | 最长 3000 字 | 描述本集反转 |
| 结尾悬念 | 多行文本 | 否 | 空 | 最长 2000 字 | 描述本集结尾悬念 |
| 预计时长 | 数字输入 | 否 | 项目单集时长 | 大于 0 且不超过 2 分钟 | 用于节奏估算 |
| 状态 | 下拉选择 | 是 | `draft` | `draft` / `confirmed` / `needs_review` | 展示为草稿、已确认、需要检查 |

### 6.2 单集故事正文字段

| 字段/控件 | 类型 | 是否必填 | 默认值 | 校验/约束 | 说明 |
| --- | --- | --- | --- | --- | --- |
| 集数 | 只读文本 | 是 | 当前集 | 必须在项目集数范围内 | 左侧列表选择 |
| 上游大纲参考 | 左中栏只读信息组 | 否 | 分集大纲内容 | 跟随分集大纲 | 展示分集标题、本集梗概、开场钩子、本集冲突、关键反转和结尾悬念，不在正文页编辑 |
| 正文内容 | 纸面化长文本编辑器 | 否 | 空 | 支持长文本编辑 | 保存为单集故事正文，是页面视觉中心 |
| 正文摘要 | 左中栏多行文本 | 否 | 空 | 最长 2000 字 | 正文完成后的成稿摘要，供后续集数作为前文上下文 |
| 前文参考 | 左中栏只读文本 | 否 | 上一集正文摘要 | 跟随上一集单集故事正文 | 第 1 集显示无前文；第 N 集直接展示第 N-1 集正文摘要，不在正文页手动编辑 |
| 质检备注 | 右侧参考区多行文本 | 否 | 空 | 最长 3000 字 | 暂为人工备注，AI 质检后续接入 |
| 字数 | 正文编辑区标题栏只读统计 | 否 | 0 | 根据正文内容实时计算 | 不要求用户手动输入 |
| 状态 | 正文编辑区标题栏下拉选择 | 是 | `draft` | `draft` / `confirmed` / `needs_review` | 保存正文状态 |

### 6.3 AI 创作控件

“正文创作”已形成可用闭环，其余控件仍只展示入口：

| 控件 | 类型 | 状态 | 展示说明 |
| --- | --- | --- | --- |
| 正文创作 | 按钮 | 有有效本集大纲时可用 | 基于固定上下文生成候选稿，采用前不覆盖正文 |
| 续写 | 按钮 | 禁用或展示“暂未接入”提示 | 后续基于正文末尾续写 |
| 润色 | 按钮 | 禁用或展示“暂未接入”提示 | 后续优化语言和节奏 |
| 撤销润色 | 按钮 | 禁用或展示“暂未接入”提示 | 后续回退润色版本 |
| 摘要 | 按钮 | 禁用或展示“暂未接入”提示 | 后续自动生成正文摘要 |
| 一致性质检 | 按钮 | 禁用或展示“暂未接入”提示 | 后续检查设定、角色和前文冲突 |
| 角色参考 | 面板入口 | 可展示静态入口 | 本阶段不新增后端 AI 能力 |
| 设定参考 | 面板入口 | 可展示静态入口 | 本阶段不新增后端 AI 能力 |
| 文风 | 面板入口 | 可展示静态入口 | 本阶段不保存独立文风库 |
| 灵感 | 面板入口 | 可展示静态入口 | 本阶段不保存独立灵感库 |

## 7. 交互与状态

- 初始状态：默认进入故事大纲或最近一次使用的子功能；没有分集时根据项目集数生成空列表占位。
- 加载中：分集列表、当前集大纲、当前集正文分别展示加载状态。
- 保存中：保存按钮禁用，并展示“保存中”。
- 保存成功：展示“已保存”，并刷新当前集状态。
- 保存失败：保留用户输入，展示中文错误。
- 空数据：当前集未保存过大纲或正文时展示空表单，不阻止编辑。
- 未保存状态：用户修改当前表单后切换集数或离开页面，应提示保存或放弃修改。
- `needs_review` 状态：展示“需要检查”，但不阻止继续编辑和保存。
- 正文创作：生成期间锁定当前集切换；刷新后恢复最近未处理候选稿。
- 其余 AI 展示按钮：点击时不发送请求，应展示“该 AI 能力暂未接入，后续完善”。

## 10. 桌面端布局要求

- 第一期单集故事正文工作台默认面向桌面端使用，不要求移动端专门适配。
- 桌面端四区布局应保证正文编辑区是页面视觉中心。
- 桌面端建议优先保证 `1280px` 及以上宽度下可用。
- 左侧分集列表、写作上下文、正文编辑区和右侧参考面板应保持稳定列宽。
- AI 按钮组在桌面端应保持可扫描，不允许文字溢出按钮。
- 长正文编辑区不应导致桌面端页面横向溢出。

## 11. 验收标准

- `/projects/[id]/story-text` 可进入故事文本页面。
- 页面展示故事大纲、分集大纲、单集故事正文三个子功能入口。
- 用户可以从分集列表选择任意一集。
- 用户可以编辑并保存当前集分集大纲。
- 用户可以编辑并保存当前集单集故事正文和正文摘要。
- 单集故事正文保存后刷新页面可以回显。
- 保存单集故事正文后，同集短剧制作内容展示为需要检查。
- 正文编辑区标题栏展示字数、状态和保存按钮。
- 上游大纲参考放在左中写作上下文区只读展示，来源为分集大纲；前文参考只读展示上一集正文摘要；正文摘要仍在正文页编辑。
- 正文节拍不作为一期正文页独立展示字段；如后续 AI 需要节拍输入，应由分集大纲中的开场钩子、本集冲突、关键反转和结尾悬念组合生成。
- 正文编辑区采用纸面化长文编辑样式，并且是页面视觉中心。
- 顶部模块导航空白区展示 AI 创作按钮组，左中栏只保留上游大纲参考和正文元信息。
- 右侧参考面板使用设定、角色、文风、灵感 tabs，并展示质检入口。
- 正文创作生成持久化候选稿，候选稿采用前不覆盖正式正文。
- 点击其余未接入 AI 按钮时展示中文提示。
- 单集故事正文和单集剧本在页面文案中明确区分。
- `npm --prefix apps/web run typecheck` 通过。

## 12. 非目标

- 不实现续写、润色、撤销润色、摘要和一致性质检的后端调用。
- 不实现候选稿逐字差异对比或复杂版本管理。
- 不新增独立文风库、灵感库或参考资料库。
- 不在故事文本页面直接编辑项目世界观或项目角色快照。
- 不生成单集剧本、分镜、字幕或发布文案；这些属于短剧制作入口。
