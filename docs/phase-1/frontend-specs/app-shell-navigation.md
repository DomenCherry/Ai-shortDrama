# 前端页面 Spec：全局工作台导航

## 1. 页面信息

- 页面组名称：全局工作台导航
- 影响范围：所有 `apps/web` 页面
- 关联技术规范：[前端风格规范](../../technical/frontend-style-guide.md)

## 2. 页面目标

全局左侧导航用于承载 AI 短剧工作台的一层模块入口，让用户在项目管理、角色卡库、世界观库和模型配置之间快速切换。

本次新增目标：

- 左侧导航支持点击收起。
- 收起后再次点击同一控制按钮可以展开。
- 收起状态下主内容区域自动获得更多横向空间。
- 不改变现有导航入口和页面路由。

## 3. 信息架构

左侧导航包含：

- 品牌区：AI 短剧工作台。
- 折叠控制按钮。
- 导航入口：
  - 项目管理。
  - 角色卡库。
  - 世界观库。
  - 模型配置。

## 4. 交互规则

- 默认进入应用时，左侧导航为展开状态。
- 用户点击折叠按钮后，导航进入收起状态。
- 用户再次点击折叠按钮后，导航恢复展开状态。
- 收起状态下仍应保留可点击导航入口，不能完全隐藏导航能力。
- 收起状态应持久化到浏览器本地状态，刷新页面后尽量保持用户上次选择。
- 折叠按钮必须有可访问名称，便于屏幕阅读器识别当前操作是“收起”还是“展开”。

## 5. 布局结构

展开状态：

```text
app-shell
├── sidebar 240px
│   ├── brand
│   ├── collapse button
│   └── nav links with full labels
└── main content
```

收起状态：

```text
app-shell
├── sidebar 72px
│   ├── short brand
│   ├── expand button
│   └── nav links with compact labels
└── main content
```

## 6. 字段与控件

| 控件 | 类型 | 状态 | 说明 |
| --- | --- | --- | --- |
| 折叠按钮 | button | 展开 / 收起 | 点击后切换左侧导航宽度 |
| 导航入口 | link | 正常 | 收起状态下仍可点击 |

## 7. API 依赖

无后端 API 依赖。

## 8. 桌面端布局要求

- 第一期全局导航默认面向桌面端使用，不要求移动端专门适配。
- 桌面端展开宽度为 240px。
- 桌面端收起宽度为 72px。
- 收起/展开过程中主内容区不应覆盖导航。

## 9. 验收标准

- 用户可以点击左侧导航按钮收起菜单。
- 用户可以再次点击同一按钮展开菜单。
- 收起后导航入口仍可点击。
- 收起后主内容区域宽度增加。
- 刷新页面后尽量保持上次折叠状态。
- `npm --prefix apps/web run typecheck` 通过。

## 10. 非目标

- 不新增新的导航入口。
- 不实现多级菜单。
- 不实现用户级导航偏好同步到后端。
