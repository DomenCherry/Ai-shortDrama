# 前端规格：模型 API 配置

## 1. 配置入口

建议在应用左侧导航或顶部导航中增加"设置"入口。

设置页包含：

- 文本生成模型配置。
- 图片生成模型配置。

图片模型配置区应支持两种配置方式：

- 供应商预设：系统提供默认 API 地址、接口路径和能力说明。
- 自定义配置：用户自行填写供应商名称、API 地址、模型名称和图片能力。

第一期只需要单用户配置，不需要团队级配置、成员权限或多工作区配置。

## 2. 文本生成模型配置区

用途：

- 配置脚本文案相关的文本生成模型。
- 测试文本生成接口是否可用。
- 查看、编辑、删除历史上保存的文本模型配置。

区域划分：

- 上方：配置列表，展示当前所有已保存的文本模型配置。
- 下方：新建/编辑表单，用于创建新配置或修改已有配置。

配置列表字段：

- 供应商名称。
- 模型名称。
- 最近测试状态。
- 启用状态。
- 更新时间。
- 操作按钮（编辑 / 删除 / 设为启用）。

表单字段：

- 供应商名称。
- API Base URL。
- API Key。
- 模型名称。
- 备注。

核心操作：

- 查看配置列表。
- 新建配置。
- 编辑已有配置。
- 删除配置。
- 切换启用/停用。
- 测试连接。
- 清空未保存修改。

状态展示：

- 未配置。
- 已配置，未测试。
- 测试成功。
- 测试失败。
- 最近测试时间。
- 最近失败原因。

## 3. 图片生成模型配置区

用途：

- 配置人物示意图生成模型。
- 测试图片生成接口是否可用。
- 查看、编辑、删除历史上保存的图片模型配置。

区域划分：

- 上方：配置列表，展示当前所有已保存的图片模型配置。
- 下方：新建/编辑表单，用于创建新配置或修改已有配置。

配置列表字段：

- 供应商名称。
- 模型名称。
- 最近测试状态。
- 启用状态。
- 更新时间。
- 操作按钮（编辑 / 删除 / 设为启用）。

表单字段：

- 配置方式。
- 供应商名称。
- 供应商预设。
- API Base URL。
- API Key。
- 模型名称。
- 图片尺寸。
- 是否支持参考图输入。
- 备注。

第一期建议内置的图片供应商预设：

| 预设 | 默认供应商名称 | 默认 API Base URL | 默认接口路径 | 参考图输入 | 主要用途 |
| --- | --- | --- | --- | --- | --- |
| `volcengine_seedream` | 火山方舟 Seedream | `https://ark.cn-beijing.volces.com/api/v3` | `/images/generations` | 支持 | 角色示意图、角色三视图 |

火山方舟 Seedream 只是第一批预设之一。后续可继续增加阿里百炼、腾讯混元、OpenAI-compatible、SiliconFlow 等预设；自定义配置始终保留。

图片尺寸第一期可以使用文本输入或简单选项，例如：

- 1024x1024。
- 1024x1536。
- 1536x1024。

核心操作：

- 查看配置列表。
- 新建配置。
- 编辑已有配置。
- 删除配置。
- 切换启用/停用。
- 测试连接。
- 清空未保存修改。

状态展示：

- 未配置。
- 已配置，未测试。
- 测试成功。
- 测试失败。
- 最近测试时间。
- 最近失败原因。

## 4. 错误提示

| 场景 | 提示文案 |
| --- | --- |
| 供应商名称为空 | 请填写供应商名称 |
| API Base URL 为空 | 请填写 API 地址 |
| API Base URL 格式错误 | API 地址必须以 http:// 或 https:// 开头 |
| API Key 为空 | 请填写 API Key |
| 模型名称为空 | 请填写模型名称 |
| 供应商预设不可用 | 该供应商预设暂不可用，请选择自定义配置 |
| 文本模型未配置 | 请先配置文本生成模型 API |
| 图片模型未配置 | 请先配置图片生成模型 API |
| 文本模型未测试成功 | 文本生成模型暂不可用，请先完成接口测试 |
| 图片模型未测试成功 | 图片生成模型暂不可用，请先完成接口测试 |
| API Key 错误 | API Key 无效，请检查后重试 |
| 模型不存在 | 模型名称不可用，请检查模型配置 |
| 网络不可达 | 接口无法访问，请检查 API 地址或网络连接 |
| 响应格式异常 | 接口响应格式无法解析，请检查供应商配置 |
| 额度不足 | 接口额度不足或无调用权限 |
| 参考图输入不支持 | 当前图片模型不支持参考图输入，请更换模型或关闭参考图能力 |

## 5. 交互流程

接口合同、软删除策略、测试日志保留、API Key 安全和生成任务前置校验以后端接口 Spec 为准：[模型 API 配置后端 Spec](../backend-specs/model-api-settings.md)。

### 5.1 保存文本模型配置

```text
用户进入设置页
 -> 填写文本模型配置
 -> 点击保存
 -> 系统校验字段
 -> 保存成功
 -> 状态显示为已配置，未测试
```

### 5.2 测试文本模型

```text
用户点击测试连接
 -> 系统发送轻量文本测试请求
 -> 接口返回可解析文本
 -> 系统记录测试成功
 -> 状态显示为测试成功
```

### 5.3 测试图片模型

```text
用户点击测试连接
 -> 系统发送轻量图片测试请求
 -> 接口返回可解析图片结果
 -> 系统记录测试成功
 -> 状态显示为测试成功
```

### 5.4 保存火山方舟 Seedream 预设图片配置

```text
用户进入设置页
 -> 图片模型配置选择供应商预设
 -> 选择火山方舟 Seedream
 -> 系统自动填充默认 API Base URL 和接口路径
 -> 用户填写 API Key、模型名称和图片尺寸
 -> 点击保存
 -> 系统保存为当前启用图片模型配置
```

### 5.5 测试失败

```text
用户点击测试连接
 -> 接口调用失败或响应不可解析
 -> 系统记录测试失败
 -> 展示失败原因
 -> 用户修改配置后再次测试
```

### 5.6 查看配置列表

```text
用户进入设置页
 -> 文本/图片配置区上方展示配置列表
 -> 列表展示供应商名称、模型名称、测试状态、启用状态、更新时间
 -> 用户可点击编辑、删除或设为启用
```

### 5.7 编辑配置并保存

```text
用户在配置列表中点击编辑
 -> 系统将该配置数据加载到下方表单
 -> API Key 字段展示为占位符（如已保存）
 -> 用户修改字段后点击保存
 -> 系统校验字段
 -> 保存成功，该配置的 last_test_status 重置为 untested
 -> 列表刷新
```

### 5.8 删除配置

```text
用户在配置列表中点击删除
 -> 系统提示删除后配置将从列表移除，历史测试记录会保留
 -> 用户确认删除
 -> 系统将该配置软删除，并设为 enabled=false
 -> 列表刷新
```

删除规则：

- 删除配置后应从列表移除，历史测试记录保留。
- 删除当前启用的唯一配置后，该类型生成能力不可用，页面应引导用户重新配置模型。
- 具体软删除、日志保留和启用状态处理以后端接口 Spec 为准。

### 5.9 启用/停用配置

```text
用户在配置列表中点击"设为启用"
 -> 系统将该配置设为 enabled=true
 -> 自动将该 config_type 下其他配置设为 enabled=false
 -> 列表刷新，展示最新启用状态
```
