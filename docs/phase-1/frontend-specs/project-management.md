# 前端规格：项目管理

## 1. 导航入口

左侧导航中，项目相关能力只保留一个一级入口：

- 项目管理。

导航规则：

- 用户点击"项目管理"进入项目列表页。
- "创建项目"只作为项目管理页内的主按钮或空状态入口出现。
- 不在左侧导航中同时展示"项目"和"创建项目"，避免两个入口表达同一组项目能力。
- 从项目创建页取消或返回时，应回到项目管理页。

## 2. 项目列表页

项目列表页是项目管理入口，用于查看已有项目，并创建新项目。

核心元素：

- 页面标题：项目管理。
- 页面说明：展示已有短剧项目，支持继续编辑或创建新项目。
- 创建项目主按钮，位于页面标题区或列表工具区。
- 项目列表。

项目卡片展示字段：

- 项目名称。
- 题材类型。
- 目标平台。
- 集数。
- 单集时长。
- 总时长。
- 当前进度。
- 更新时间。

当前实现说明：

- 项目卡片中的当前进度暂时展示项目 `status`，第一期 v1 通常为 `draft`。
- 真实阶段进度，如已加载资产、已填写大纲、已填写剧本等，后续通过项目工作台内容聚合后再展示。

空状态：

- 当没有任何项目时，展示空状态提示。
- 提供明显的创建项目入口，文案应引导用户创建第一个短剧项目。

核心操作：

- 创建项目。
- 进入项目工作台。
- 编辑项目基础信息。

## 3. 项目创建页

项目创建页用于录入新项目基础信息。

页面结构：

```text
项目创建页
├── 基础信息
│   ├── 项目名称
│   ├── 创意描述
│   ├── 目标平台
│   ├── 题材类型
│   ├── 目标受众
│   └── 内容风格
├── 时长配置
│   ├── 集数
│   ├── 单集时长
│   └── 总时长预览
├── 备注
└── 操作区
    ├── 取消
    └── 创建项目
```

页面原则：

- 创意描述是最重要的输入，应给较大输入区域。
- 集数和单集时长应靠近展示，并实时计算总时长。
- 时长错误应在用户输入后即时显示。
- 创建按钮在非法状态下禁用，或点击后显示明确错误。

## 4. 项目基础信息编辑入口

用户进入项目工作台后，应能编辑项目基础信息。

当前实现采用项目工作台阶段导航：

- 用户进入 `/projects/{project_id}` 后，默认停留在"基础信息"阶段。
- "基础信息"阶段复用项目创建字段，支持保存和还原。
- 项目概览区域只展示摘要，不直接展开编辑表单。
- 世界观与角色加载、项目内微调和移除操作发生在项目工作台的"世界观与角色"阶段，不放在项目创建页中。
- 每个项目最多加载一个项目世界观；项目角色可以加载多个，但同一角色卡不能重复加载到同一项目。
- 项目内微调世界观或角色只更新当前项目快照，不修改世界观库或角色卡库原始内容。

编辑行为：

- 修改项目名称、目标平台、题材、目标受众、内容风格、备注时，可以直接保存。
- 修改集数或单集时长时，必须重新进行时长校验。
- 如果项目已经有后续内容，修改项目设定、集数或单集时长后，下游整体故事大纲、分集大纲、单集故事正文、剧本、分镜和文案应标记为需要检查。

## 5. 交互流程

### 5.1 创建项目流程

```text
用户点击左侧项目管理
 -> 进入项目列表页
 -> 点击创建项目
 -> 进入项目创建页
 -> 输入创意描述
 -> 填写或使用默认集数
 -> 填写或使用默认单集时长
 -> 系统实时计算总时长
 -> 系统执行字段校验
 -> 用户点击创建项目
 -> 校验通过
 -> 保存项目
 -> 进入项目工作台
```

### 5.2 创建失败流程

```text
用户点击创建项目
 -> 系统发现必填项为空或时长超限
 -> 阻止保存
 -> 显示具体错误提示
 -> 用户修改输入
 -> 再次提交
```

### 5.3 编辑项目基础信息流程

```text
用户进入项目工作台
 -> 点击编辑项目信息
 -> 修改基础字段
 -> 系统重新计算总时长
 -> 系统执行校验
 -> 校验通过后保存
```

如果修改集数或单集时长，且项目已经生成分集大纲或剧本，系统应提示：

```text
修改集数或单集时长可能影响已生成的分集大纲和剧本，保存后建议重新检查或重新生成相关内容。
```

## 6. API 依赖

| 行为 | 前端方法 | 后端接口 |
| --- | --- | --- |
| 获取项目列表 | `listProjects` | `GET /api/projects` |
| 创建项目 | `createProject` | `POST /api/projects` |
| 获取单个项目 | `getProject` | `GET /api/projects/{project_id}` |
| 更新项目 | `updateProject` | `PUT /api/projects/{project_id}` |
