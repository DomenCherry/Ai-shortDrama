# 结构化剧本工作台页面 Spec

## 1. 页面信息

- 页面名称：结构化剧本工作台
- 页面路径：`/projects/[id]/production`，短剧制作模块下的“剧本”一级入口
- 所属阶段：第一期，短剧制作 / 结构化剧本
- 关联 PRD：[结构化剧本](../module-prds/production/structured-script.md)
- 关联功能设计：[外部 AI 视频工具制作包](../module-prds/production/external-ai-production-package.md)
- 关联后端 Spec：[结构化剧本后端接口](../backend-specs/structured-script.md)
- 目标用户：个人短剧创作者

## 2. 页面目标

本页面将当前集单集故事正文转换成由有序场次和有序内容块组成的正式生产剧本，并支持用户在不覆盖正式内容的前提下预览、采用或放弃 AI 候选结果。

用户进入页面时通常已经创建项目，并具备当前集分集大纲、单集故事正文以及部分世界观和角色快照。用户离开页面时，应能够保存结构化草稿、提交待确认或确认一个可被分镜模块追溯读取的正式剧本版本。

上游和下游关系：

```text
项目资料 / 资产 + 故事文本（只读上游）
 -> 结构化剧本工作台
 -> 分镜制作、后期准备、制作包（下游）
```

本页面不得修改世界观、角色、整体故事大纲、分集大纲或单集故事正文。

## 3. 用户流程

### 3.1 首次生成

```text
进入短剧制作 / 剧本
 -> 选择集数并查看上游完整性提示
 -> 当前集无正式剧本时，点击“生成结构化剧本”
 -> 填写可选指令并确认生成上下文
 -> 查看候选场次、内容块、时长和与当前正式稿的差异
 -> 采用候选或放弃候选
 -> 继续人工编辑并保存
 -> 运行一致性检查
 -> 提交待确认或确认剧本
```

### 3.2 人工编辑

```text
选择正式剧本
 -> 新增、编辑、删除或排序场次
 -> 新增、编辑、删除或排序内容块
 -> 查看自动时长、人工时长和目标偏差
 -> 显式保存完整剧本聚合
 -> 查看保存结果和下游需要检查提示
```

### 3.3 局部生成

```text
在场次菜单选择“重新生成场次”，或勾选一个或多个连续内容块后选择“局部改写”
 -> 选择预设方向并填写可选指令
 -> 预览仅覆盖目标范围的候选结果
 -> 采用前处理当前未保存修改
 -> 采用候选并刷新正式剧本
```

## 4. 信息架构

### 4.1 顶部制作导航与集数工具栏

沿用短剧制作模块导航，展示：

- 一级入口：剧本、分镜、后期准备、制作包。
- 当前集数选择；展示集数、分集标题和上游风险标记。
- 剧本状态：草稿、待确认、已确认、需要检查。
- 版本号和最近保存时间。
- 目标时长、最终生效时长和偏差。
- 主要操作：生成整集、保存、检查、提交待确认、确认剧本。

集数切换不得静默丢弃当前未保存修改。

### 4.2 场次导航与主编辑区

桌面端使用“左侧场次列表 + 右侧当前场次详情”的主从布局。左侧按正式顺序展示：

- 场次号、标题或地点。
- 生效时长和内容块数量。
- 对应检查问题数量。
- 当前选中状态和新增场次入口。

右侧一次只编辑一个场次，包含：

- 展示场次号、标题和场次操作。
- 地点、时间、内外景、出场人物。
- 自动时长、人工覆盖时长和最终生效时长。
- 默认折叠的剧情作用和场次检查结果。
- 有序内容块列表。
- 场次操作：重新生成、复制、新增内容块、删除。

内容块不按动作、对白、旁白、转场拆成四个大文本框，必须按真实叙事顺序混排。

### 4.3 内容块编辑

每个内容块展示：

- 拖拽手柄和多选框。
- 类型标记：动作、对白、旁白、转场。
- 正文。
- 对白说话人，或旁白/对白的情绪提示。
- 表演、语气、停顿或动作提示。
- 块操作：复制、在前方/后方新增、删除。

对白说话人优先从项目角色快照中选择；未关联角色时允许填写临时人物名称。角色引用和临时人物名称互斥展示，但提交时至少存在一个。

### 4.4 参考与检查抽屉

工具栏提供“参考与检查”入口并显示当前问题数量。点击后打开右侧抽屉，使用 tabs 展示：

- 来源正文：当前集完整故事正文、标题、状态和字数；正文只读、保留段落、限制最大高度并独立滚动，提供“前往编辑正文”入口。
- 上游：当前分集大纲、当前正文摘要、上一集摘要和来源正文版本。
- 角色：项目角色快照名称、身份和口吻，只读。
- 世界观：项目世界观摘要和规则，只读。
- 检查：按 `error`、`warning`、`info` 分组的一致性结果。
- 候选历史：当前集最近候选记录、状态、范围和生成时间。

抽屉默认进入来源正文页签。切换剧本集数后必须同步展示对应集正文；缺少正文时展示说明和创建入口，不展示空白内容。打开、切换或关闭抽屉不得改变剧本的未保存状态。

从候选历史打开候选预览前先关闭参考抽屉，不允许两个右侧抽屉叠加。

点击检查项时，如目标仍存在，应滚动并高亮对应场次或内容块；历史版本中已不存在的目标只展示说明。

### 4.5 候选预览层

整集候选使用大尺寸抽屉或全屏对话层；场次和内容块候选可使用右侧宽抽屉。候选预览展示：

- 生成范围、指令、预设方向、生成时间和状态。
- 正式稿与候选稿的场次级、内容块级差异摘要。
- 候选结构、自动时长和检查结果。
- 范围外内容保持不变的说明。
- 操作：采用、放弃、关闭。

第一版不要求逐字 diff；必须能明确识别新增、删除、修改和重排的场次或内容块。

## 5. 布局结构

- 使用现有 app shell、项目工作台和短剧制作模块导航。
- 顶部集数工具栏保持单行或紧凑双行，并在内容滚动时吸附于模块顶部。
- 桌面端采用“场次列表 + 场次详情”布局：列表建议 `220-260px`，详情区自适应。
- 场次卡片使用紧凑面板，不为每个字段叠加多层卡片边框。
- 场次元信息在宽屏下使用网格布局，内容块正文占据最大宽度。
- 参考与检查使用 `420-480px` 右侧抽屉，关闭后不占用编辑宽度。
- 来源正文内容区最大高度建议为 `360-440px`，超出后独立滚动；正文使用适合长文阅读的行高并保留换行。
- 拖拽期间保留明确占位，不改变其他卡片宽度。
- 第一期不要求移动端专门适配。
- 窄屏下场次列表移到详情上方并限制最大高度，来源正文仍通过右侧抽屉查看。

## 7. 交互与状态

### 7.1 加载与空状态

- 页面并行加载项目、当前集正文、正式剧本、角色快照、世界观快照和候选历史。
- 正式剧本加载失败时，不展示可编辑空表单，避免用户误以为空稿覆盖服务端内容。
- 当前集没有正式剧本但存在正文时，展示“生成结构化剧本”和“人工创建空白草稿”。
- 当前集没有故事正文时，禁用整集生成，提供“返回故事文本”入口；仍允许人工创建草稿。
- 世界观、角色或分集大纲缺失时允许生成，但在提交生成前展示连续性风险。

### 7.2 本地编辑与保存

- 第一版采用本地编辑加显式保存，不做逐字段自动保存。
- 新增、删除、复制、编辑和排序均先更新本地草稿并进入未保存状态。
- 保存时提交完整剧本聚合和当前 `revision`；服务端原子校验并写入。
- 保存中禁用再次保存、生成、提交、确认和排序操作。
- 保存成功后使用响应替换本地数据，更新 `revision`、`version`、时长和状态。
- `409` 表示服务端版本已变化；页面不得覆盖，需提示刷新并保留本地草稿供复制。
- 批量校验失败时按场次和内容块定位全部可识别错误，不只显示第一条。

### 7.3 未保存修改保护

以下行为必须先处理未保存修改：

- 切换集数或离开页面。
- 打开候选并采用。
- 提交待确认或确认剧本。
- 重新加载服务端数据。

确认层提供：保存并继续、放弃修改并继续、取消。浏览器关闭或刷新使用原生离开保护。

### 7.4 排序、删除与选择

- 场次只允许在当前剧本内排序；内容块只允许在当前场次内排序。
- 拖拽结束后立即重新计算本地展示号，正式 `sort_order` 由服务端保存时规范化。
- 删除场次前提示该操作会令关联分镜需要检查；删除最后一个场次允许保存草稿，但不能提交或确认。
- 删除内容块导致场次为空时允许继续编辑，但保存后保持草稿且不能确认。
- 局部改写允许选择同一场次内一个或多个连续块；非连续或跨场次选择时禁用改写入口并说明范围限制。

### 7.5 生成、预览与采用

- 同一集同一范围生成中，相关入口禁用，避免重复提交。
- 生成超时或失败时保留正式稿和未保存本地稿。
- 采用前要求本地无未保存修改。
- 采用整集候选替换正式剧本聚合；采用场次候选只替换目标场次内容；采用块候选只替换所选连续范围并按候选顺序插回原位置，候选块数量可以与原范围不同。
- 采用后刷新正式稿和候选历史，状态变为草稿，并展示下游需要检查提示。
- 正式稿在候选生成后已变化时，采用返回 `409`；页面保留候选预览并提示重新生成。
- 候选已采用或已放弃后，采用和放弃按钮禁用。

### 7.6 检查、提交与确认

- 编辑时前端即时执行必填和对白说话人校验；后端结果为最终标准。
- 保存不被一致性 `warning` 或 `info` 阻止。
- 提交待确认或确认前必须保存，并运行基于当前版本的结构检查。
- 存在 `error` 时阻止提交和确认，检查面板定位问题。
- `warning` 不阻止确认，但确认层展示警告数量。
- 已确认剧本发生实质内容编辑并保存后，状态自动回到 `draft`。
- 上游变化导致 `needs_review` 时保留全部内容；重新确认前必须再次检查。

## 8. API 依赖

接口合同以后端接口 Spec 为准；本节只描述页面调用关系。

| 行为 | 前端方法 | 后端接口 | 请求数据 | 响应数据 | 错误处理 |
| --- | --- | --- | --- | --- | --- |
| 读取项目 | `getProject` | `GET /api/projects/{project_id}` | 项目 ID | `Project` | 展示项目加载失败 |
| 读取当前集正文 | `getProjectEpisodeContent` | `GET /api/projects/{project_id}/episode-contents/{episode_no}` | 集数 | `ProjectEpisodeContent \| null` | 禁用整集生成或展示加载失败 |
| 读取上游大纲 | `getProjectStoryOutline` / `listProjectEpisodeOutlines` | 现有故事文本接口 | 项目 ID | 故事大纲、分集大纲 | 右侧展示缺失提示 |
| 读取世界观 | `listProjectWorldSnapshots` | `GET /api/projects/{project_id}/world-snapshots` | 项目 ID | 世界观快照列表 | 上下文面板展示加载失败 |
| 读取角色 | `listProjectCharacterSnapshots` | `GET /api/projects/{project_id}/character-snapshots` | 项目 ID | 角色快照列表 | 上下文面板展示加载失败 |
| 读取正式剧本 | `getStructuredEpisodeScript` | `GET /api/projects/{project_id}/episode-scripts/{episode_no}` | 集数 | `EpisodeScript \| null` | 禁止用空稿覆盖未知状态 |
| 保存完整聚合 | `saveStructuredEpisodeScript` | `PUT /api/projects/{project_id}/episode-scripts/{episode_no}` | `EpisodeScriptSavePayload` | `EpisodeScript` | 展示字段错误；`409` 提示并发冲突 |
| 生成候选 | `createScriptGeneration` | `POST /api/projects/{project_id}/episode-scripts/{episode_no}/generations` | 范围、目标、指令、请求标识、基准版本 | `ScriptGeneration` | 保留正式稿并允许重试 |
| 候选列表 | `listScriptGenerations` | `GET /api/projects/{project_id}/episode-scripts/{episode_no}/generations` | 状态和分页参数 | 候选摘要列表 | 历史面板展示加载失败 |
| 候选详情 | `getScriptGeneration` | `GET /api/projects/{project_id}/episode-scripts/{episode_no}/generations/{generation_id}` | 候选 ID | `ScriptGeneration` | 提示候选不存在 |
| 采用候选 | `adoptScriptGeneration` | `POST /api/projects/{project_id}/episode-scripts/{episode_no}/generations/{generation_id}/adopt` | 当前 `revision` | 候选记录和正式剧本 | `409` 提示正式稿已变化 |
| 放弃候选 | `discardScriptGeneration` | `POST /api/projects/{project_id}/episode-scripts/{episode_no}/generations/{generation_id}/discard` | 候选 ID | 候选记录 | 保留预览并提示失败 |
| 执行检查 | `checkStructuredEpisodeScript` | `POST /api/projects/{project_id}/episode-scripts/{episode_no}/checks` | 当前版本、检查模式 | `ScriptCheckResult` | 结构检查失败仍展示本地即时错误 |
| 提交待确认 | `submitStructuredEpisodeScript` | `POST /api/projects/{project_id}/episode-scripts/{episode_no}/submit-review` | 当前 `revision` | `EpisodeScript` | 展示阻止项 |
| 确认剧本 | `confirmStructuredEpisodeScript` | `POST /api/projects/{project_id}/episode-scripts/{episode_no}/confirm` | 当前 `revision` | `EpisodeScript` | 展示结构错误或并发冲突 |
| 读取正式历史 | `listStructuredEpisodeScriptVersions` | `GET /api/projects/{project_id}/episode-scripts/{episode_no}/versions` | 分页参数 | 正式版本摘要列表 | 历史入口展示加载失败 |

现有 `getProjectEpisodeScript` / `updateProjectEpisodeScript` 方法应升级类型或由上述方法替代；页面不得继续提交 `scene_text`、`dialogue`、`action_notes`、`voiceover` 四字段载荷。

## 9. 错误提示

| 场景 | 用户提示 |
| --- | --- |
| 项目不存在 | 项目不存在或已被删除 |
| 集数非法 | 集数编号必须在项目集数范围内 |
| 正式剧本加载失败 | 剧本加载失败，请重试；为避免覆盖，当前暂不可编辑 |
| 正文缺失 | 当前集还没有单集故事正文，请先返回故事文本完成正文 |
| 场次字段缺失 | 第 {scene_no} 场缺少地点、时间或内外景 |
| 场次无内容 | 第 {scene_no} 场至少需要一个非空内容块 |
| 对白无说话人 | 第 {scene_no} 场的对白缺少项目角色或临时人物名称 |
| 角色引用失效 | 第 {scene_no} 场引用的角色已不在当前项目，请重新选择或改为临时人物 |
| 并发保存冲突 | 剧本已在其他操作中更新。请刷新后合并；你的本地修改仍保留 |
| 生成失败 | 候选剧本生成失败，正式剧本未被修改，请稍后重试 |
| 采用冲突 | 正式剧本在候选生成后已变化，请基于最新剧本重新生成 |
| 检查失败 | 一致性检查未完成，请重试；已保存内容不会丢失 |
| 确认被阻止 | 剧本仍有结构错误，请修正后再确认 |
| 保存失败 | 剧本保存失败，你的本地修改仍保留 |

## 10. 桌面端布局要求

- 建议在 `1280px` 及以上宽度使用；最小可用宽度为 `1100px`。
- `1280px` 及以上时保持主编辑区和右侧上下文并列；低于该宽度时右侧面板默认折叠为抽屉。
- 场次元信息网格不得挤压地点输入到低于 `180px`。
- 内容块类型和人物控件使用固定或有限宽度，正文区域自适应。
- 长正文、剧情作用和检查信息必须换行或内部滚动，不得撑开整个页面横向宽度。
- 顶部主要操作在窄桌面下允许分为两组，但“保存”和“确认”不能被折叠到不可发现菜单中。

## 11. 验收标准

- 页面在短剧制作“剧本”入口展示结构化场次和真实顺序内容块，不再展示旧四字段表单。
- 用户可以新增、复制、编辑、删除和排序场次及内容块。
- 对白必须关联项目角色或填写临时人物名称。
- 整集生成、场次重新生成和块局部改写均先产生候选，采用前不修改正式稿。
- 局部候选采用后，范围外场次和内容块 ID、内容及顺序保持不变。
- 页面展示自动、人工和最终生效时长以及与项目目标的偏差。
- 保存使用完整聚合和 `revision`；并发冲突不会静默覆盖服务端或本地内容。
- 页面离开、切换集数和采用候选前会处理未保存修改。
- 一致性警告不阻止保存或确认；结构错误阻止提交和确认。
- 确认成功后显示正式版本；实质内容再次保存后状态回到草稿并提示下游需要检查。
- 正式剧本不存在、正文缺失、上游不完整、生成失败和候选冲突均有明确空状态或错误提示。
- 页面只读展示上游，不提供世界观、角色或故事正文编辑表单。
- 旧项目迁移后能完整显示“待整理场次”和所有迁移内容。
- `npm --prefix apps/web run typecheck` 通过。

## 12. 非目标

- 不在本页面生成、编辑或确认分镜。
- 不生成图片、视频、配音或字幕文件。
- 不提供多人实时协同编辑。
- 不提供逐字级 diff 或任意两个历史版本的复杂合并。
- 不允许内容块跨场次拖拽；跨场次移动可在后续版本评估。
- 不允许一次局部改写跨越多个场次。
- 不在前端复制后端时长估算系数或语义一致性规则。
