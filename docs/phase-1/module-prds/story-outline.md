# 模块 PRD：整体故事大纲与剧情脉络生成

> 状态：**未实现** — 本文档为占位规格，待 AI 生成能力接入后补充详细设计。

## 1. 功能定位

系统根据项目基础信息、创意描述、选题策划，以及项目内已加载的世界观和角色卡快照，生成整部短剧的故事骨架，包括起承转合、阶段性反转、情绪曲线和结局方向。

## 2. 输出内容

整体故事大纲应包含：

- 故事背景。
- 主线目标。
- 核心矛盾。
- 故事起点。
- 起承转合结构。
- 阶段性反转。
- 情绪曲线。
- 关键伏笔。
- 结局方向。
- 整体节奏建议。
- 与当前集数和总时长匹配的剧情容量建议。

## 3. 交互要求

- 用户可以编辑整体故事大纲。
- 用户可以重新生成完整故事大纲。
- 用户可以局部改写故事背景、主线目标、反转、伏笔或结局方向。
- 用户确认后的整体故事大纲应作为后续人物设定、分集大纲和单集剧本生成的核心上下文。

## 4. 数据对象

### 4.1 ProjectStoryOutline

表示整体故事大纲与剧情脉络。

字段建议：

- id
- project_id
- logline
- main_goal
- core_conflict
- character_arcs
- ending_direction
- notes
- status
- created_at
- updated_at

## 6. 验收标准

- 系统可以生成独立的整体故事大纲与剧情脉络。
- 如果项目已加载世界观或角色卡，故事大纲应优先遵循项目内快照内容。
- 用户修改整体故事大纲后，后续人物设定、分集大纲和剧本生成应基于最新大纲。
- 整体故事大纲必须在生成人物设定之前生成或由用户手动填写。
