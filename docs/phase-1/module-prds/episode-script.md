# 模块 PRD：单集剧本生成

> 状态：**未实现** — 本文档为占位规格，待 AI 生成能力接入后补充详细设计。

## 1. 功能定位

系统根据项目基础信息、选题策划、整体故事大纲、人物设定和某一集大纲生成单集剧本，并支持按改写方向重写。

## 2. 输出内容

剧本应包含：

- 集数标题。
- 场景编号。
- 场景地点。
- 场景时间。
- 出场人物。
- 动作描写。
- 人物对白。
- 情绪提示。
- 结尾悬念。
- 预计时长。

剧本格式建议：

```text
第 1 集：标题

场景 1：地点 / 时间
出场人物：角色 A、角色 B

动作：
...

对白：
角色 A：...
角色 B：...
```

## 3. 交互要求

- 用户可以编辑剧本正文。
- 用户可以重新生成整集剧本。
- 用户可以按改写方向重写剧本。
- 支持的改写方向包括：更爽、更虐、更悬疑、更口语化、更短视频化、压缩时长、增强结尾悬念。

## 4. 数据对象

### 4.1 ProjectEpisodeScript

表示单集剧本。

字段建议：

- id
- project_id
- episode_no
- scene_text
- dialogue
- action_notes
- voiceover
- status
- created_at
- updated_at

## 5. 用户故事

30. 作为个人短剧创作者，我想选择某一集生成剧本，以便开始进入具体创作。
31. 作为个人短剧创作者，我想生成完整单集剧本，以便获得可继续打磨的文本。
32. 作为个人短剧创作者，我想剧本包含场景、动作和对白，以便后续可以转分镜和拍摄。
33. 作为个人短剧创作者，我想改写剧本为更爽或更悬疑，以便测试不同表达方式。
34. 作为个人短剧创作者，我想压缩剧本时长，以便适配单集 2 分钟以内的短视频节奏。

## 6. 验收标准

- 系统可以生成完整单集剧本。
- 剧本与当前整体故事大纲、人物设定和分集大纲保持一致。
- 剧本预计时长不应超过项目设置的单集时长。
- 用户可以编辑并保存剧本。
- 用户可以对剧本进行至少一种方向的改写。
