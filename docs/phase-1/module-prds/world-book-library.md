# 模块 PRD：世界观库

## 1. 功能定位

世界观库用于独立管理可复用的故事世界设定。

它解决的问题是：用户可能会反复创作同一题材、同一系列或同一世界观下的多个短剧项目，不希望每次都重新输入时代背景、世界规则、组织关系、地点设定和风格约束。

世界观库只管理资产库中的原始世界观内容。世界观被加载到项目后，会生成项目内快照副本；项目内快照的编辑和引用规则见 [创作资产库](./creative-asset-library.md)。

资产类型包括：

- 世界观资产：用于保存题材、时代背景、世界规则、组织、地点、阶层、禁忌、整体风格等长期设定。
- 世界观条目：用于拆分世界观中的地点、组织、人物关系背景、关键规则、历史事件等可被生成任务引用的内容。

## 2. 用户目标

- 用户可以创建一个可复用世界观。
- 用户可以把大型世界观拆成多个结构化条目，便于后续生成时引用。
- 用户可以查看、编辑、停用或归档世界观。
- 用户可以在项目创建或项目工作台中选择世界观加载到项目。
- 用户可以知道某个世界观被哪些项目使用过。

## 3. 功能范围

第一期需要支持：

- 世界观列表。
- 世界观新建。
- 世界观详情查看。
- 世界观基础信息编辑。
- 世界观条目管理。
- 世界观状态管理。
- 世界观被项目加载前的预览。

第一期暂不支持：

- 多人共享世界观。
- 世界观市场或模板商城。
- 复杂关键词自动触发规则。
- 自动把资产库新版本同步到已加载项目。
- 世界观版本差异对比。

## 4. 字段设计

### 4.1 WorldBook

表示一个可复用世界观资产。

| 字段 | 说明 |
| --- | --- |
| id | 唯一标识 |
| name | 世界观名称 |
| genre | 题材类型 |
| era_background | 时代背景 |
| world_rules | 核心世界规则 |
| organizations | 主要组织 |
| locations | 主要地点 |
| social_structure | 社会结构或势力关系 |
| taboo_or_constraints | 禁忌、限制或不可违反的设定 |
| tone_style | 整体风格 |
| summary | 短摘要，用于列表和项目加载预览 |
| version | 版本号 |
| status | 状态（draft / active / archived） |
| created_at | 创建时间 |
| updated_at | 更新时间 |

### 4.2 WorldEntry

表示世界观中的一个可引用条目。

| 字段 | 说明 |
| --- | --- |
| id | 唯一标识 |
| world_book_id | 所属世界观 |
| title | 条目标题 |
| entry_type | 条目类型 |
| keywords | 关键词 |
| content | 条目正文 |
| applicable_scope | 适用范围（全局、特定角色、特定地点、特定剧情阶段） |
| priority | 优先级 |
| status | 状态（active / disabled） |
| created_at | 创建时间 |
| updated_at | 更新时间 |

### 4.3 ProjectWorldSnapshot

表示项目加载世界观后的快照副本。

| 字段 | 说明 |
| --- | --- |
| id | 唯一标识 |
| project_id | 所属项目 |
| source_world_book_id | 来源世界观 ID |
| source_version | 来源世界观版本 |
| name | 世界观名称（快照副本） |
| genre | 题材类型（快照副本） |
| snapshot_content | 世界观基础信息快照内容 |
| entry_snapshot_content | 世界观条目快照内容 |
| loaded_at | 加载时间 |
| updated_at | 更新时间 |

规则：

- 项目生成任务读取该快照，不直接读取 `WorldBook` 原文。
- 修改该快照不影响资产库原始世界观。

## 5. 状态规则

世界观状态：

- `draft`：草稿。
- `active`：可加载。
- `archived`：已归档。

条目状态：

- `active`：可被加载和引用。
- `disabled`：暂不参与加载和引用。

规则：

- 只有 `active` 世界观可以被加载到项目。
- 已归档世界观不从历史项目中删除。
- 世界观内容发生影响生成上下文的修改时，应提升版本号。
- 删除已被项目加载过的世界观风险较高，第一期建议使用归档代替硬删除。

## 6. 项目加载规则

用户在项目创建或项目工作台中选择世界观后，系统应把当前世界观内容复制为项目内快照。

快照内容应包括：

- 世界观基础信息。
- 当前启用的世界观条目。
- 来源世界观 ID。
- 来源世界观版本。
- 加载时间。

加载后：

- 项目生成任务读取项目内快照。
- 用户在项目内修改世界观快照，不影响世界观库原始内容。
- 用户在世界观库修改原始内容，不自动覆盖项目内快照。

## 7. 生成引用规则

世界观库本身不直接参与生成。生成任务应通过项目内快照读取世界观内容。

当项目已加载世界观时：

- 选题策划应参考世界观题材、风格和核心规则。
- 故事大纲应遵守世界规则、组织关系和主要地点设定。
- 人物设定应符合世界观中的阶层、组织、禁忌和时代背景。
- 分集大纲和剧本应避免违反已加载世界观规则。

当项目未加载世界观时：

- 系统仍可按原有创意输入生成。
- 用户可以后续再加载世界观，但需要提示已有内容可能需要重新校准。

## 8. 用户故事

以下用户故事提取自 PRD §13，与世界观库相关：

- **#52** 作为个人短剧创作者，我想独立管理世界观资产，以便在多个短剧项目中复用同一套设定。
- **#54** 作为个人短剧创作者，我想把世界观和角色卡加载到项目中，以便让当前项目基于已有素材继续创作。
- **#55** 作为个人短剧创作者，我想在项目工作台的"世界观与角色"阶段内直接选择并加载已有世界观和角色卡，以便无需跳转到资产库页面即可完成加载。
- **#57** 作为个人短剧创作者，我想在项目内修改已加载的世界观或角色卡，以便适配当前项目而不破坏原始资产。
- **#58** 作为个人短剧创作者，我想看到项目内容来自哪个原始资产，以便追踪素材来源。
- **#59** 作为个人短剧创作者，我想把项目内修改后的世界观或角色卡另存为新资产，以便沉淀新的可复用素材。

## 9. 验收标准

来自功能说明与 PRD §15.3 的世界观相关标准：

- 用户可以创建世界观。
- 用户可以编辑世界观基础信息。
- 用户可以新增、编辑、停用世界观条目。
- 用户可以在列表中搜索和筛选世界观。
- 用户可以把 `active` 世界观加载到项目。
- 加载到项目后会生成项目内快照，并保留来源 ID 和来源版本。
- 项目内修改世界观快照不会改变世界观库原始内容。
- 世界观库原始内容更新不会自动覆盖项目内快照。
- 已归档世界观不再作为新项目可选项，但历史项目来源仍可追踪。
- 同一个世界观资产可以被多个项目加载，项目内修改互不影响。
- 修改项目内世界观副本时，资产库原始内容不变。
- 修改资产库原始内容时，已加载项目不会被自动覆盖。
- 项目已加载世界观时，整体故事大纲、人物设定、分集大纲和剧本生成应优先引用项目内快照。

## 10. 后续扩展

- 支持世界观版本差异对比。
- 支持按关键词、角色、地点和剧情阶段动态选择条目。
- 支持从项目内快照另存为新世界观。
- 支持世界观模板。
- 支持世界观之间的系列关系。
