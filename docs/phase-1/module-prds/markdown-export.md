# 模块 PRD：Markdown 导出

> 状态：**未实现** — 本文档为占位规格，待 AI 生成能力接入后补充详细设计。

## 1. 功能定位

用户可以将当前项目内容导出为 Markdown 文件，用于后续编辑、备份或交给其他工具继续处理。Markdown 导出是第一期唯一必须支持的导出格式。

## 2. 输出内容

导出内容应包括：

- 项目基础信息。
- 集数、单集时长和总时长。
- 项目内加载的世界观快照及来源说明。
- 项目内加载的角色卡快照及来源说明。
- 选题策划。
- 整体故事大纲与剧情脉络。
- 人物设定。
- 人物示意图引用。
- 分集大纲。
- 已生成的单集剧本。

导出文件命名建议：

```text
项目名称-短剧策划与剧本.md
```

## 3. 交互要求

- 用户可以一键导出当前项目全部内容。
- 导出内容以项目当前状态为准，不直接导出资产库最新版本。
- 导出不包含 API Key。

## 4. 数据对象

该模块不引入新数据对象，导出内容来自项目内已有数据。

## 5. 用户故事

41. 作为个人短剧创作者，我想导出 Markdown，以便在其他工具中继续编辑或备份。
42. 作为个人短剧创作者，我想在导出内容中看到人物示意图引用，以便后续制作时统一角色形象。

## 6. 验收标准

- 用户可以导出 Markdown。
- 导出的 Markdown 结构清晰。
- 导出内容与当前项目内容一致。
- 导出文件可以被普通 Markdown 编辑器打开。
- 已确认人物示意图应以图片地址、本地路径或引用说明的方式出现在导出内容中。
- 导出不包含 API Key。
