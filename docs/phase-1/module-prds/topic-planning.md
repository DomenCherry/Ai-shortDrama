# 模块 PRD：选题策划生成

> 状态：**未实现** — 本文档为占位规格，待 AI 生成能力接入后补充详细设计。

## 1. 功能定位

系统根据项目基础信息和创意描述，生成结构化选题策划，帮助创作者从多个方向中选择最适合的短剧故事方向。

## 2. 输出内容

选题策划应包含以下结构化输出：

- 剧名候选，建议 5 个。
- 一句话故事。
- 故事卖点。
- 目标用户画像。
- 核心冲突。
- 核心爽点或情绪点。
- 前 3 秒开头钩子建议。
- 整体风格建议。
- 风险提示，例如题材俗套、冲突不够强、集数支撑不足等。

## 3. 交互要求

- 用户可以选择一个剧名作为项目名称。
- 用户可以编辑选题策划内容。
- 用户可以重新生成完整选题策划。
- 用户可以针对某一部分单独改写。

## 4. 数据对象

### 4.1 TopicPlan

表示选题策划结果。

字段建议：

- project_id
- title_candidates
- logline
- selling_points
- audience_profile
- core_conflict
- emotional_points
- opening_hooks
- style_suggestion
- risk_notes

## 5. 用户故事

7. 作为个人短剧创作者，我想生成多个剧名候选，以便选择更适合传播的标题。
8. 作为个人短剧创作者，我想生成一句话故事，以便快速判断故事是否清晰。
9. 作为个人短剧创作者，我想生成故事卖点，以便明确这个短剧为什么值得看。
10. 作为个人短剧创作者，我想生成目标用户画像，以便判断内容是否匹配观众。
11. 作为个人短剧创作者，我想生成核心冲突，以便故事有足够的戏剧张力。
12. 作为个人短剧创作者，我想生成开头钩子，以便短剧前几秒能抓住观众。
13. 作为个人短剧创作者，我想编辑选题策划，以便保留自己的创作判断。

## 6. 验收标准

- 系统可以生成结构化选题策划。
- 用户可以编辑并保存结果。
- 用户可以基于选题策划继续生成整体故事大纲与剧情脉络。
