# 模块 PRD：分集大纲与单集故事正文创作

> 状态：**未实现** — 本文档定义分集大纲生成，以及故事文本入口下的单集故事正文创作工作台。

## 1. 功能定位

本模块位于整体故事大纲之后、单集剧本和短剧制作之前。它负责把整部短剧拆成可推进的分集结构，并进一步把每一集写成可读的故事 / 小说化正文。

模块包含两层产物：

- 分集大纲：定义每集标题、梗概、钩子、冲突、反转、悬念和时长。
- 单集故事正文：基于对应分集大纲写成完整故事文本，作为短剧制作生成剧本、分镜、字幕和发布文案的主要输入。

单集故事正文不是短剧剧本。它关注故事叙述、剧情推进、人物心理、场景氛围和阅读连续性；单集剧本则关注视频生产所需的场景、动作、对白、旁白和时长控制。

## 2. 分集大纲输出内容

每集分集大纲应包含：

- 集数编号。
- 本集标题。
- 开头钩子。
- 主要剧情。
- 主要冲突。
- 关键反转。
- 结尾悬念。
- 出场人物。
- 本集作用。
- 预计时长。

默认决策：

- 第一期支持用户在时长规则内自由设置集数。
- 如果用户未填写集数，默认生成 20 集。
- 单集时长默认 1 分钟，且不能超过 2 分钟。

## 3. 单集故事正文创作工作台

用户在故事文本入口中选择某一集后，进入单集故事正文创作工作台。工作台采用三栏结构：

- 左侧分集列表：展示所有集数、标题、状态、完成提示和当前集高亮。
- 中间正文编辑区：展示当前集标题、字数、状态、正文内容、保存和 AI 写作操作。
- 右侧参考面板：展示上下文、世界观、角色、设定、文风 / 参考资料、灵感和质检结果。

单集故事正文应包含：

- 集数编号。
- 正文内容。
- 正文摘要。
- 正文钩子 / 传播点。
- 正文节拍。
- 字数统计。
- 当前状态：`draft`、`confirmed`、`needs_review`。
- 前文参考，例如前几集正文摘要、上集结尾和未回收伏笔。

单集故事正文页应只读引用分集大纲中的标题、本集梗概、开场钩子、本集冲突、关键反转和结尾悬念；这些字段属于写作计划，不在正文页重复编辑。

## 4. AI 创作能力

第一期完整覆盖参考界面的创作辅助能力，但按本产品的故事文本边界重新命名和组织，不要求照搬暗色视觉风格或具体按钮文案。

AI 创作控制台应支持：

- 正文创作：基于当前集大纲、整体故事大纲、世界观、角色和前文上下文生成单集故事正文。
- 续写：基于当前正文末尾继续写作。
- 润色：提升语言质感、节奏、爽点、悬念或人物情绪。
- 撤销润色：回到润色前版本。
- 摘要：从当前正文提取正文摘要，供后续集数作为上下文。
- 钩子提取：从当前正文提取或优化正文钩子、结尾悬念和传播点。
- 一致性质检：检查正文是否违背世界观、角色设定、分集大纲、时间线、伏笔或前文参考。
- 角色参考：在右侧面板查看当前项目角色，辅助保持人物口吻、关系和动机一致。
- 设定参考：在右侧面板查看世界观、历史事件、组织、地点、规则和不可修改设定。
- 文风 / 参考资料面板：沉淀写作规则、风格参考、外部参考摘要或用户指定的表达偏好。
- 灵感面板：沉淀可选桥段、冲突点、反转方向、情绪节拍或短剧爽点。

## 5. 交互要求

- 用户可以生成完整分集大纲。
- 用户可以编辑每集大纲。
- 用户可以重新生成全部分集大纲。
- 用户可以单独改写某一集大纲。
- 用户可以从分集列表选择任意一集进入正文创作。
- 用户可以手动编辑单集故事正文。
- 用户可以基于本集大纲生成、续写、润色、撤销润色正文。
- 用户可以对当前正文生成正文摘要和正文钩子 / 传播点。
- 用户可以查看右侧世界观、角色、设定、文风 / 参考资料、灵感和质检结果。
- 用户可以保存当前单集故事正文并设置状态。
- 保存或确认单集故事正文后，同集短剧制作下游内容应进入 `needs_review`。
- 用户可以基于已保存单集故事正文进入单集剧本生成。

## 8. 验收标准

- 系统可以按照指定集数生成完整大纲。
- 每集都包含钩子、冲突、反转和悬念。
- 分集大纲应遵循整体故事大纲与最新人物设定。
- 用户可以从分集列表选择任意一集进入单集故事正文创作。
- 用户可以只读查看上游大纲参考并编辑正文。
- 用户可以基于当前集大纲生成或续写正文。
- 用户可以对正文做润色、撤销润色、摘要和钩子提取。
- 用户可以在右侧查看世界观、角色、设定、文风 / 参考资料、灵感和质检结果。
- 单集故事正文保存后可以回显。
- 单集故事正文保存或确认后，同集剧本、分镜和文案标记为 `needs_review`。
- 单集故事正文与单集剧本在文档和界面中应被明确区分。
- 用户可以基于已保存单集故事正文进入剧本生成。

## 9. 实现决策

- 本模块不新增独立 PRD 文件，直接扩展原“分集大纲”模块。
- 单集故事正文创作归属于故事文本，不归属于短剧制作。
- 短剧制作仍以已保存或已确认的单集故事正文为主要输入。
- 右侧世界观和角色面板在正文创作页中作为参考使用；如需修改世界观或角色，用户必须回到项目资料 / 资产。
- “文网”在第一期解释为文风 / 参考资料面板，用于沉淀写作规则、风格参考或外部参考摘要。
- 参考界面的能力覆盖指功能层面，不要求照搬暗色视觉风格、按钮文案或布局细节。
