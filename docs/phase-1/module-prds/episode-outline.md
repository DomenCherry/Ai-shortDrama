# 模块 PRD：分集大纲生成

> 状态：**未实现** — 本文档为占位规格，待 AI 生成能力接入后补充详细设计。

## 1. 功能定位

系统根据选题策划、整体故事大纲和人物设定生成完整分集大纲，确保每集都有钩子、冲突、反转和悬念，符合短剧节奏。

## 2. 输出内容

每集分集大纲应包含：

- 集数编号。
- 本集标题。
- 开头钩子。
- 主要剧情。
- 主要冲突。
- 关键反转。
- 结尾悬念。
- 出场人物。
- 本集作用。
- 预计时长。

默认决策：

- 第一期支持用户在时长规则内自由设置集数。
- 如果用户未填写集数，默认生成 20 集。
- 单集时长默认 1 分钟，且不能超过 2 分钟。

## 3. 交互要求

- 用户可以编辑每集大纲。
- 用户可以重新生成全部大纲。
- 用户可以单独改写某一集。
- 用户可以基于某一集生成完整剧本。

## 4. 数据对象

### 4.1 ProjectEpisodeOutline

表示单集大纲。

字段建议：

- id
- project_id
- episode_no
- title
- synopsis
- hook
- conflict
- reversal
- cliffhanger
- duration_minutes
- status
- created_at
- updated_at

## 5. 用户故事

26. 作为个人短剧创作者，我想生成完整分集大纲，以便知道整部短剧如何推进。
27. 作为个人短剧创作者，我想每集都有钩子、冲突、反转和悬念，以便符合短剧节奏。
28. 作为个人短剧创作者，我想编辑某一集大纲，以便调整剧情节奏。
29. 作为个人短剧创作者，我想单独重新生成某一集大纲，以便解决某集不够精彩的问题。

## 6. 验收标准

- 系统可以按照指定集数生成完整大纲。
- 每集都包含钩子、冲突、反转和悬念。
- 分集大纲应遵循整体故事大纲与最新人物设定。
- 用户可以选择任意一集进入剧本生成。
