# 模块 PRD：创作资产库（架构总则）

## 1. 功能定位

创作资产库是跨世界观库、角色卡库两大子系统的架构总则文档，定义资产与项目之间的加载、隔离、追踪规则。

本期内资产库服务于两个目标：

- 让创作者沉淀可复用的世界观和角色设定。
- 让具体短剧项目可以加载这些资产，并在项目内独立调整，避免修改当前项目时破坏原始资产。

各子模块的完整字段定义、CRUD 细节和页面交互说明见独立文档：

- [世界观库](./world-book-library.md)
- [角色卡库](./character-card-library.md)

### 1.1 本期范围

需要支持：

- 世界观和角色卡的创建、编辑、查看。
- 项目创建或工作台中加载世界观和角色卡，生成项目内快照。
- 项目中查看和编辑已加载的快照。
- 生成任务引用项目快照。
- Markdown 导出包含项目当前资产快照，并标注来源。

暂不实现：

- 多人共享资产库。
- 复杂版本差异对比。
- 自动同步资产库新版本。
- 复杂关键词触发和 prompt 插入位置配置。
- 可视化人物关系图。

## 2. 核心原则

### 2.1 资产库与项目分离

资产库中的世界观和角色卡是可复用原始内容。项目中的世界观和角色卡是加载后的快照副本。两者必须分离：

- 修改资产库原始内容，不自动修改已加载到项目中的内容。
- 修改项目内副本，不自动修改资产库原始内容。
- 项目生成任务只读取项目内副本，确保当前项目上下文稳定。

### 2.2 加载不是实时引用

用户将世界观或角色卡加载到项目时，系统复制一份快照到项目中。

快照需保留：

- 原始资产 ID。
- 原始资产版本。
- 加载时间。
- 项目内当前内容。

资产库负责沉淀，项目快照负责当前项目一致性。

### 2.3 可追踪但不自动覆盖

资产库原始内容更新后，已加载项目可显示"来源有新版本"，但系统不能自动覆盖项目内内容。

用户可选择：

- 保持当前项目快照不变。
- 手动同步来源新版本并确认覆盖范围。
- 将项目内改动另存为新的资产。

本期只实现来源信息展示和手动另存，不要求复杂差异对比。

## 3. 加载流程概要

资产库到项目涉及三个核心流程：

### 3.1 资产创建

在世界观库或角色卡库中创建可复用的原始资产，填写结构化设定后保存。

### 3.2 项目加载

在项目创建页或项目工作台中选择世界观和角色卡资产，系统生成项目内快照。用户可按当前项目需要编辑快照内容。

项目加载限制：

- 每个项目最多加载一个世界观快照。
- 每个项目可以加载多个角色快照。
- 同一角色卡不能在同一项目中重复加载为多个项目角色快照。
- 项目内世界观和角色快照可以微调，微调不回写资产库原始内容。

### 3.3 生成引用

项目内世界观快照 + 角色卡快照 + 项目基础信息，共同作为生成任务的上下文输入，用于生成选题策划、故事大纲、人物设定、分集大纲和单集剧本。

## 4. 生成上下文优先级

生成任务组装上下文时，应优先使用项目内快照。优先级规则：

1. **临时要求**：用户在当前生成表单中输入的临时要求。
2. **已确认内容**：项目内最新故事大纲、人物设定、分集大纲等。
3. **项目快照**：项目内世界观和角色卡快照。
4. **项目基础信息**：项目级别的元数据。
5. **资产库原始内容**：仅在项目未加载快照且用户明确引用时才读取，读取前先生成快照。

正常情况下第 5 项不直接进入生成上下文。

## 5. 导出来源追踪

Markdown 导出以项目当前状态为准，不直接导出资产库最新版本。

导出内容应包含：

- 当前项目使用的世界观快照。
- 当前项目使用的角色卡快照。
- 每个快照的来源资产名称。
- 每个快照的来源版本。
- 项目内是否经过编辑。
- 已确认的人物示意图引用。

## 6. 跨资产验收标准

以下为跨资产共性验收标准，各子模块的专属验收标准见对应文档。

### 6.1 隔离性

- 同一世界观资产加载到两个项目后，两个项目内修改互不影响。
- 同一角色卡资产加载到两个项目后，两个项目内修改互不影响。
- 同一项目内只能有一个世界观快照。
- 同一项目内不能重复加载同一角色卡。
- 修改项目内快照不会改变资产库原始内容。
- 修改资产库原始内容不会自动覆盖项目内快照。

### 6.2 生成引用

- 整体故事大纲生成应能引用项目内世界观和角色卡快照。
- 人物设定生成应能引用项目内角色卡快照。

### 6.3 导出与追踪

- Markdown 导出应包含项目当前使用的世界观和角色卡，并标注来源。

### 6.4 CRUD 完整性

- 各类资产的创建、编辑、查看操作完整可用（详见子模块文档）。

## 7. 实现顺序

1. 资产库文档与数据模型设计。
2. 世界观和角色卡基础 CRUD（见各子模块文档）。
3. 项目加载资产并生成快照。
4. 故事大纲和人物设定生成读取项目快照。
5. 导出和来源追踪展示。
