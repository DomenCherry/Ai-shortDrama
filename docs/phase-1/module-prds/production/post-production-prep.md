# 模块 PRD：后期准备

> 状态：**模块边界已确认，待详细设计**

## 1. 问题陈述

分镜完成后，创作者仍需要手工整理配音稿、字幕、音效、音乐和剪辑说明，数据容易重复、遗漏或与镜头时长不一致。

## 2. 解决方案

从结构化剧本和正式分镜生成可编辑的后期资料，以剪映等外部剪辑工具能够使用的通用文件和清单为交付目标。

## 3. 输入与输出

输入：正式剧本、正式分镜、人物信息、镜头时长和声音内容。

输出：

- 分角色配音稿和旁白稿。
- 带时间轴的字幕及 SRT。
- BGM、音效和转场建议。
- 镜头顺序、素材命名和剪辑说明。
- 平台标题、简介和发布文案。

## 4. 功能范围

- 按角色汇总对白。
- 维护情绪、语速、语气和停顿提示。
- 从对白和旁白生成字幕条目。
- 编辑字幕开始时间、结束时间和文本。
- 生成 BGM、音效和转场建议。
- 生成剪辑节奏说明和素材命名清单。
- 检查字幕长度、对白覆盖和音画时长。
- 维护平台标题、简介和发布文案。

## 6. 剪映适配原则

第一阶段向剪映工作流交付：

- SRT 字幕。
- 镜头顺序表。
- 素材命名规范。
- 剪辑说明。
- 音效与 BGM 清单。

在剪映工程格式和稳定接入方式确认前，不承诺直接生成剪映工程文件。

## 7. 状态与依赖

- 剧本或分镜变化后，后期准备标记为需要检查。
- 后期资料变化后，已生成制作包标记为需要检查。
- 自动重新计算字幕时间轴前必须保护用户手动调整，采用候选或确认机制。

## 8. 用户故事

1. 作为配音人员，我想按角色查看完整对白，以便连续录制。
2. 作为配音人员，我想看到情绪和语速提示，以便准确表演。
3. 作为剪辑人员，我想导入 SRT 字幕，以便减少重复录入。
4. 作为剪辑人员，我想查看镜头顺序和素材名称，以便快速定位素材。
5. 作为短剧创作者，我想获得音效和转场建议，以便改善节奏。
6. 作为运营人员，我想获得平台标题和发布文案，以便准备发布。

## 9. 验收标准

- 系统可以从正式剧本和分镜生成配音及字幕候选内容。
- 用户可以编辑配音提示和字幕时间轴。
- 系统可以导出合法 SRT。
- 对白、旁白和字幕之间存在可检查的来源关系。
- 系统可以输出剪辑说明、素材命名和声音建议清单。
- 上游变化后正确标记后期资料状态。

## 10. 测试决策

- 重点测试字幕时间合法性、SRT 序号和时间格式、角色对白归组及来源追溯。
- 测试手动时间轴不会被自动生成静默覆盖。
- 剪映相关测试验证通用交付文件，不依赖剪映客户端。

## 11. 非目标

- 不提供音频录制或语音合成工作站。
- 不提供在线视频时间线剪辑。
- 不直接生成剪映工程文件。
- 不自动发布到平台。

## 12. 待细化问题

- 字幕时间轴生成与重算规则。
- 配音稿字段和导出格式。
- 音效、BGM 和转场建议的数据结构。
- 发布文案是否继续放在后期准备内。
