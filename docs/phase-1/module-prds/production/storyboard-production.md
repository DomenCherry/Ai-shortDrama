# 模块 PRD：分镜制作

> 状态：**详细设计已确认，待前后端 Spec 与实现**

## 1. 问题陈述

结构化剧本不能直接作为 AI 图片或视频工具的生产输入。创作者需要把场次拆成镜头，并为每个镜头维护画面、主体、动作、声音、时长、连续性和外部生成提示词。

现有分镜只有镜头序号、场景、画面提示词、机位、时长和对白等粗粒度字段，缺少剧本来源追溯、场次分组、候选版本、人物与场景参考、提示词保护和制作状态。

## 2. 解决方案

以单场为基本分镜生成单位，以整集批量生成作为编排入口。正式分镜由场次分组的有序镜头组成，AI 素材提示词是镜头内部内容，不单独设置一级模块。

```text
结构化剧本场次
  -> 候选镜头组
     -> 正式镜头
        -> 通用提示词
        -> Seedance 适配提示词
```

所有 AI 生成均先产生候选结果，用户采用后才更新正式分镜。

## 3. 输入与输出

### 3.1 输入

- 当前结构化剧本及来源版本。
- 剧本场次和有序内容块。
- 项目角色快照及已确认人物参考素材。
- 项目世界观和场景信息。
- 项目视觉风格、目标画幅和目标单集时长。
- 用户本次分镜或提示词生成指令。

### 3.2 输出

- 按场次分组的正式镜头列表。
- 镜头级画面、主体、动作、声音、时长和连续性信息。
- 与剧本内容块的来源关系和可编辑制作文本快照。
- 平台无关的通用图片、视频和负面提示词。
- 可编辑的 Seedance 适配提示词。
- 首帧、尾帧文字描述和人物、场景参考素材引用。
- 可供后期准备和制作包导出的正式分镜版本。

## 4. 功能范围

### 4.1 分镜生成

- 以单场为基本单位生成候选镜头组。
- 提供“生成整集分镜”入口，按场次批量编排生成任务。
- 整集批量生成允许部分成功，并明确展示失败场次。
- 候选结果采用前不修改正式镜头。
- 用户可以按场次预览、采用或放弃候选镜头组。

### 4.2 镜头编辑

- 新增、复制、编辑、删除和排序镜头。
- 在同一场次内调整镜头顺序。
- 将镜头重新归属到其他有效场次。
- 编辑必填与可选镜头字段。
- 自动重新计算展示编号和时长汇总。
- 单镜头重新生成只产生该镜头候选，不影响范围外镜头。

### 4.3 提示词

- 根据镜头结构字段生成平台无关的通用提示词。
- 生成图片提示词、视频提示词和负面提示词。
- 维护可选首帧和尾帧文字描述。
- 引用项目人物和场景参考素材。
- 从通用镜头数据生成 Seedance 适配提示词。
- 通用提示词和 Seedance 适配提示词均允许用户编辑。
- 修改 Seedance 适配提示词不反向修改核心镜头数据。
- 核心镜头字段变化后，已存在提示词标记为“需要更新”，不得自动覆盖用户修改。

### 4.4 检查与确认

- 检查镜头必填字段。
- 检查剧本对白和旁白覆盖。
- 检查镜头与来源场次、内容块的关系。
- 检查人物与场景连续性。
- 检查主要角色参考素材缺失。
- 检查场次和整集时长偏差。
- 检查提示词是否需要更新。
- 分镜整体状态由镜头状态和结构检查结果汇总。

## 5. 镜头编号规则

- 每个镜头使用不会因排序变化而改变的稳定内部 ID。
- 展示编号采用“场次号-镜头号”，例如 `S01-001`。
- 场次内排序或场次排序变化后，自动更新展示编号。
- 展示编号变化不能影响镜头内部 ID、历史版本或外部引用。
- 导出时同时提供稳定 ID 和当前展示编号。

## 7. 必填与可选规则

镜头必填字段：

- 所属有效场次。
- 景别。
- 主体描述。
- 画面描述。
- 动作。
- 大于 0 的镜头时长。

可选字段：

- 机位。
- 运镜。
- 构图。
- 出镜角色。
- 表情。
- 环境补充。
- 道具。
- 对白、旁白、音效和音乐。
- 连续性说明。
- 首帧和尾帧描述。
- 外部参考素材。

## 8. 剧本来源与文本快照

- 镜头可以引用一个或多个剧本内容块。
- 对白和旁白同时保存来源内容块引用与可编辑制作文本快照。
- 剧本变化后，系统比较来源块与制作快照并标记差异。
- 剧本变化不能自动覆盖镜头中的制作文本。
- 用户可以选择同步来源文本、保留制作文本或手动合并。
- 来源场次删除后，关联镜头保留并将 `source_status` 设为 `scene_deleted`。
- 来源场次已删除的镜头不能进入已确认状态，用户必须删除、重新归属或重新生成。

## 9. 时长规则

- 每个镜头时长必须大于 0。
- 场次时长等于其正式镜头时长之和。
- 整集时长等于全部正式镜头时长之和。
- 场次镜头总时长与剧本场次生效时长偏差超过 10% 时显示警告。
- 整集镜头总时长与剧本整集生效时长偏差超过 10% 时显示警告。
- 时长偏差不阻止保存，但在确认和导出前持续展示。

## 10. 人物与场景参考规则

- 镜头可以引用多个项目人物和场景参考素材。
- 出镜主要角色没有已确认参考图时显示一致性警告。
- 缺少参考图不阻止保存、生成或确认。
- 参考素材被替换或移除后，相关镜头提示词标记为需要更新。
- 参考素材仅保存项目内引用，不复制到镜头记录中。

## 11. 提示词更新与保护

- 通用提示词由镜头字段和参考素材生成。
- Seedance 适配提示词由通用镜头数据和适配模板生成。
- 用户手动编辑提示词后，`customized` 设为 true。
- 核心镜头字段、参考素材或风格变化后，提示词设为 `needs_update`。
- 系统不得自动覆盖用户手动修改的提示词。
- 用户可以预览重新生成结果，再决定采用或保留原提示词。
- 修改 Seedance 适配提示词不会反向修改镜头、通用提示词或其他适配结果。

## 12. 状态与下游门槛

### 12.1 镜头状态

- `draft`：正在编辑或来源为草稿剧本。
- `pending_review`：内容基本完成，等待人工确认。
- `confirmed`：已确认，可进入后期准备和正式制作包。
- `needs_review`：剧本、参考素材或镜头核心信息变化，需要复核。

### 12.2 分镜整体状态

分镜整体状态根据镜头状态和结构检查结果汇总：

- 存在结构错误时不能确认。
- 存在 `needs_review` 镜头时整体为 `needs_review`。
- 全部镜头已确认且无结构错误时，整体可以确认为 `confirmed`。
- 草稿剧本生成的分镜只能保持草稿或待确认，不能作为正式制作包输入。
- 正式制作包要求全部镜头无结构错误；一致性警告可以带警告导出。

### 12.3 状态传播

- 来源剧本版本变化后，分镜标记为需要检查。
- 镜头或提示词发生实质变化后，后期准备和制作包标记为需要检查。
- 仅变更展示编号不触发下游需要检查。

## 13. 候选版本与保留规则

- 单场生成和单镜头重新生成都必须先产生候选版本。
- 候选采用前不得更新正式镜头。
- 采用单场候选只替换目标场次的镜头集合。
- 采用单镜头候选只替换目标镜头内容，并保留稳定镜头 ID。
- 范围外镜头不得改变。
- 已采用生成记录永久保留。
- 未采用候选按单集最多保留最近 20 个，超出后清理最旧未采用候选。

## 14. 一致性与结构检查

结构错误：

- 缺少有效来源场次。
- 来源场次已删除且未处理。
- 缺少镜头必填字段。
- 镜头时长小于等于 0。
- 镜头排序冲突或重复。

一致性警告：

- 剧本对白或旁白未被任何镜头覆盖。
- 镜头制作文本与来源剧本存在差异。
- 主要角色缺少已确认参考图。
- 人物、服装、道具或场景连续性风险。
- 通用或 Seedance 提示词需要更新。
- 场次或整集时长偏差超过 10%。

## 15. 交互要求

### 15.1 页面结构

- 顶部展示集数、来源剧本版本、分镜状态、镜头数量、总时长和主要操作。
- 主区域按场次分组展示镜头。
- 场次标题展示剧本时长、镜头时长和偏差。
- 镜头列表支持紧凑浏览、排序和批量选择。
- 镜头详情展示核心字段、声音、提示词、参考素材和检查结果。
- 提示词属于镜头详情，不设置独立一级导航。

### 15.2 生成与采用

- “生成整集分镜”按场次编排任务并展示逐场进度。
- 单场生成和单镜头重生成展示候选对比。
- 采用前提示影响范围。
- 生成失败时保留正式镜头，并允许只重试失败场次。

### 15.3 编辑保护

- 删除镜头前提示对对白覆盖、时长和下游内容的影响。
- 重新归属场次后自动更新展示编号和时长统计。
- 核心字段变化后明确展示提示词需要更新。
- 切换集数、场次或候选前必须处理未保存修改。

## 16. 旧数据迁移

现有分镜镜头迁移规则：

- 保留原镜头 ID、序号、场景、画面提示词、机位、时长和对白或旁白。
- 尝试根据场景文本和顺序匹配结构化剧本场次。
- 无法匹配时保留镜头并标记为缺少有效来源场次。
- 原画面提示词迁移为自定义通用视频提示词，标记 `customized=true`。
- 无法可靠拆分的机位、运镜和构图保留在机位或迁移备注中。
- 所有迁移镜头状态设为 `needs_review`。
- 迁移不得丢失任何非空原始文本。

## 18. 验收标准

- 系统可以按单场生成候选镜头，并支持整集批量编排。
- 候选采用前不修改正式分镜。
- 每个镜头使用稳定内部 ID 和自动派生展示编号。
- 镜头包含所属场次、景别、主体、画面、动作和大于 0 的时长。
- 用户可以新增、复制、编辑、删除、排序和重新归属镜头。
- 单镜头重新生成不影响范围外镜头。
- 镜头可以追溯剧本内容块并维护可编辑制作文本快照。
- 剧本变化不自动覆盖镜头制作文本。
- 通用和 Seedance 提示词均可编辑，核心字段变化后正确标记需要更新。
- 用户手动修改的提示词不会被自动覆盖。
- 系统显示场次及整集时长和超过 10% 的偏差警告。
- 主要角色缺少参考图时警告但不阻止保存。
- 来源场次删除后镜头保留并阻止确认，直到用户处理。
- 分镜整体状态正确汇总镜头状态和结构错误。
- 正式制作包要求全部镜头无结构错误。
- 旧分镜迁移不丢失文本并标记为需要检查。

## 19. 实现决策

- 以 `Storyboard` 作为聚合根，镜头排序、归属和采用通过聚合操作完成。
- 分镜批量生成使用场次级任务编排，允许部分成功和定向重试。
- 提示词生成封装为独立服务，输入平台无关镜头模型，输出通用提示词。
- Seedance 适配封装为独立适配器，不污染核心镜头字段。
- 剧本来源差异检测封装为独立服务，不自动修改制作文本。
- 时长汇总和 10% 偏差检查封装为纯计算服务。
- 分镜确认校验封装为独立验证器，返回结构化错误和警告。
- 镜头展示编号为派生值，不能作为数据库主键或外部稳定引用。

## 20. 测试决策

测试只验证外部行为和业务合同，不绑定具体 UI 组件或内部函数。

必须覆盖：

- 单场生成、整集编排、部分失败和失败重试。
- 候选预览、采用、放弃和幂等请求。
- 镜头新增、复制、删除、排序、重新归属及展示编号计算。
- 单镜头重新生成的影响范围。
- 必填字段、时长正数和来源场次校验。
- 剧本内容块引用、制作文本快照和差异检测。
- 提示词自定义保护、过期标记和重新生成采用。
- Seedance 适配器输入输出合同。
- 人物和场景参考素材变化。
- 场次及整集时长汇总和 10% 偏差警告。
- 来源场次删除后的镜头保留与确认阻止。
- 镜头状态和分镜整体状态汇总。
- 20 条未采用候选上限及正式版本保护。
- 旧分镜迁移完整性和幂等性。
