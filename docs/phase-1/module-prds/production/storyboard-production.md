# 模块 PRD：分镜制作

> 状态：**详细设计已确认，待前后端 Spec 与实现**

## 1. 问题陈述

结构化剧本不能直接作为 AI 图片或视频工具的生产输入。创作者需要把场次拆成镜头，并为每个镜头维护画面、主体、动作、声音、时长、连续性和外部生成提示词，并继续把已确认提示词转成可追踪的视频生成任务。

现有分镜只有镜头序号、场景、画面提示词、机位、时长和对白等粗粒度字段，缺少剧本来源追溯、场次分组、候选版本、人物与场景参考、提示词保护、视频生成任务状态、生成结果版本和制作状态。

## 2. 解决方案

以单场为基本分镜生成单位，以整集批量生成作为编排入口。正式分镜由场次分组的有序镜头组成，AI 素材提示词是镜头内部内容，不单独设置一级模块。

```text
结构化剧本场次
  -> 候选镜头组
     -> 正式镜头
        -> 单一视频提示词
        -> 文生视频生成任务
           -> 候选视频结果
           -> 已采用镜头素材
```

分镜和提示词类 AI 生成均先产生候选结果，用户采用后才更新正式分镜。视频生成结果不反向修改分镜文本，只作为镜头素材候选；用户明确采用后才成为该镜头的当前视频素材。

### 2.1 剧本与分镜关系

- 结构化剧本是分镜的上游输入；分镜不是剧本的替代编辑器。
- 一个项目的同一集只有一个当前正式剧本聚合，也只有一个当前正式分镜聚合。
- 分镜聚合创建时记录来源剧本 ID、来源剧本版本和来源剧本状态。
- 剧本场次决定分镜工作台的场次分组；镜头通过 `source_scene_id` 归属到某个剧本场次。
- 镜头可以引用一个或多个剧本内容块 `source_block_ids`，用于追踪该镜头覆盖了哪些动作、对白、旁白或转场。
- 镜头中的对白、旁白、动作、画面和提示词是制作快照，允许为了拍摄和生成素材进行局部改写。
- 编辑分镜镜头、提示词或视频生成结果不反向修改结构化剧本。
- 剧本发生实质变化后，已有分镜和镜头保留，但整体状态与受影响镜头应标记为需要检查。
- 若剧本场次被删除或镜头无法匹配有效场次，镜头进入未归属或来源异常状态，等待用户重新归属。
- 已确认分镜进入制作包时必须能追溯到明确的剧本版本；来源剧本未确认时，制作包应给出风险提示。

## 3. 输入与输出

### 3.1 输入

- 当前结构化剧本及来源版本。
- 剧本场次和有序内容块。
- 项目角色快照及已确认人物参考素材。
- 项目世界观和场景信息。
- 项目视觉风格、目标画幅和目标单集时长。
- 用户本次分镜或提示词生成指令。
- 当前启用且测试成功的视频生成模型配置。
- 用于视频生成的镜头视频提示词、负面词、首尾帧描述和参考素材。

### 3.2 输出

- 按场次分组的正式镜头列表。
- 镜头级画面、主体、动作、声音、时长和连续性信息。
- 与剧本内容块的来源关系和可编辑制作文本快照。
- 单一视频提示词、负面词和首尾帧约束。
- 首帧、尾帧文字描述和人物、场景参考素材引用。
- 镜头级视频生成任务、任务状态、失败原因和生成结果引用。
- 每个镜头已采用的视频素材记录。
- 可供后期准备和制作包导出的正式分镜版本。

## 4. 功能范围

### 4.1 分镜生成

- 以单场为基本单位生成候选镜头组。
- 提供“生成整集分镜”入口，按场次批量编排生成任务。
- 整集批量生成允许部分成功，并明确展示失败场次。
- 候选结果采用前不修改正式镜头。
- 用户可以按场次预览、采用或放弃候选镜头组。

### 4.2 镜头编辑

- 新增、复制、编辑、删除和排序镜头。
- 在同一场次内调整镜头顺序。
- 将镜头重新归属到其他有效场次。
- 编辑必填与可选镜头字段。
- 自动重新计算展示编号和时长汇总。
- 单镜头重新生成只产生该镜头候选，不影响范围外镜头。

### 4.3 提示词

- 根据镜头结构字段生成并维护单一视频提示词。
- 维护视频提示词、负面提示词和可选首尾帧文字描述。
- 引用项目人物和场景参考素材。
- 图片提示词和 Seedance 专用提示词不在本期分镜提示词 Tab 暴露。
- Seedance 等供应商适配由后端视频生成服务处理，不要求用户维护多份提示词。
- 核心镜头字段变化后，已存在提示词标记为“需要更新”，不得自动覆盖用户修改。

### 4.4 视频生成与结果管理

- 支持从单个镜头调用当前启用的视频生成模型。
- 默认使用单一视频提示词；旧数据仅在视频提示词为空时兼容读取 Seedance 适配提示词。
- 视频生成前由后端统一组装最终提示词：基础视频提示词 + 出镜角色视觉锚点 + 关键镜头视觉字段 + 首尾帧约束 + 负面提示词。
- 出镜角色视觉锚点来自项目角色快照的 `name`、`gender`、`role_type` 和 `visual_description`；缺少视觉描述或参考图时只提示一致性风险，不阻止生成。
- 核心画面、主体、动作、景别、机位、运镜、构图、表情、环境和道具会进入文生视频提示词；对白、旁白、音效、音乐和连续性备注不直接进入文生视频请求。
- 生成前检查视频模型配置、提示词、镜头时长、参考素材可读性和提示词新鲜度。
- 视频生成任务必须异步执行并展示 queued / running / succeeded / failed / canceled 状态。
- 任务提交后保存输入快照、模型配置、供应商任务 ID、请求摘要和幂等键。
- 生成成功后保存结果 URL、本地文件引用或供应商结果引用，以及缩略图、时长、尺寸等可获得的元信息。
- 生成失败时保留正式分镜、提示词和已有视频结果，并记录可理解的失败原因。
- 同一镜头可以保留多个候选视频结果。
- 用户可以预览候选视频结果，并将其中一个标记为该镜头的已采用素材。
- 采用视频结果不修改镜头核心字段或视频提示词。
- 核心镜头字段、参考素材或提示词变化后，已采用视频素材标记为可能过期，但不自动删除。

### 4.5 检查与确认

- 检查镜头必填字段。
- 检查剧本对白和旁白覆盖。
- 检查镜头与来源场次、内容块的关系。
- 检查人物与场景连续性。
- 检查主要角色参考素材缺失。
- 检查场次和整集时长偏差。
- 检查提示词是否需要更新。
- 检查已采用视频素材是否与当前提示词和参考素材一致。
- 分镜整体状态由镜头状态和结构检查结果汇总。

## 5. 镜头编号规则

- 每个镜头使用不会因排序变化而改变的稳定内部 ID。
- 展示编号采用“场次号-镜头号”，例如 `S01-001`。
- 场次内排序或场次排序变化后，自动更新展示编号。
- 展示编号变化不能影响镜头内部 ID、历史版本或外部引用。
- 导出时同时提供稳定 ID 和当前展示编号。

## 7. 必填与可选规则

镜头必填字段：

- 所属有效场次。
- 景别。
- 主体描述。
- 画面描述。
- 动作。
- 大于 0 的镜头时长。

可选字段：

- 机位。
- 运镜。
- 构图。
- 出镜角色。
- 表情。
- 环境补充。
- 道具。
- 对白、旁白、音效和音乐。
- 连续性说明。
- 首帧和尾帧描述。
- 外部参考素材。

## 8. 剧本来源与文本快照

- 镜头可以引用一个或多个剧本内容块。
- 对白和旁白同时保存来源内容块引用与可编辑制作文本快照。
- 剧本变化后，系统比较来源块与制作快照并标记差异。
- 剧本变化不能自动覆盖镜头中的制作文本。
- 用户可以选择同步来源文本、保留制作文本或手动合并。
- 来源场次删除后，关联镜头保留并将 `source_status` 设为 `scene_deleted`。
- 来源场次已删除的镜头不能进入已确认状态，用户必须删除、重新归属或重新生成。

## 9. 时长规则

- 每个镜头时长必须大于 0。
- 场次时长等于其正式镜头时长之和。
- 整集时长等于全部正式镜头时长之和。
- 场次镜头总时长与剧本场次生效时长偏差超过 10% 时显示警告。
- 整集镜头总时长与剧本整集生效时长偏差超过 10% 时显示警告。
- 时长偏差不阻止保存，但在确认和导出前持续展示。

## 10. 人物与场景参考规则

- 镜头可以引用多个项目人物和场景参考素材。
- 出镜主要角色没有已确认参考图时显示一致性警告。
- 缺少参考图不阻止保存、生成或确认。
- 参考素材被替换或移除后，相关镜头提示词标记为需要更新。
- 参考素材仅保存项目内引用，不复制到镜头记录中。

## 11. 提示词更新与保护

- 视频提示词由镜头字段和参考素材生成。
- Seedance 等供应商适配由视频生成服务在提交任务时完成。
- 用户手动编辑提示词后，`customized` 设为 true。
- 核心镜头字段、参考素材或风格变化后，提示词设为 `needs_update`。
- 系统不得自动覆盖用户手动修改的提示词。
- 用户可以预览重新生成结果，再决定采用或保留原提示词。
- 修改视频提示词不会反向修改镜头核心字段。

## 12. 视频生成规则

### 12.1 生成前置条件

从镜头发起文生视频生成前必须满足：

- 存在当前启用的视频模型配置。
- 视频模型配置最近测试状态为 `success`。
- 镜头存在有效来源场次，且必填字段完整。
- 镜头时长大于 0。
- 存在可用的视频提示词。
- 使用的提示词不是 `needs_update`，或用户明确选择带风险继续生成。
- 引用的参考素材可以读取；缺失参考素材时应提示风险。
- 主角人物一致性依赖项目角色快照的视觉描述和参考图状态；缺失时前端提示风险，后端仍允许提交单镜头生成任务。
- 用户可以在视频生成界面为本次任务手动调整分辨率、画幅和时长；不调整时使用默认参数。

### 12.1.1 视频提示词字段来源

- 必须进入：`video_prompt`、`negative_prompt`、`first_frame_description`、`last_frame_description`、出镜角色快照视觉锚点。
- 作为镜头视觉补充进入：`subject_description`、`visual_description`、`action`、`shot_size`、`camera_angle`、`camera_movement`、`composition`、`expression`、`environment`、`props`。
- 本期不进入文生视频：`dialogue_snapshot`、`voiceover_snapshot`、`sound_effect`、`music_note`、`source_block_ids`、`source_scene_id`、`continuity_note`、`image_prompt`。

### 12.2 任务与轮询

- 视频生成任务提交必须使用幂等键，避免重复点击创建重复任务。
- 任务提交后立即创建 `ShotVideoGeneration` 记录。
- 对异步供应商，系统应保存供应商任务 ID 并支持轮询或手动刷新状态。
- 对同步返回结果的供应商，系统仍按统一任务记录保存结果。
- 分辨率、画幅和时长属于单次生成参数，记录在请求 payload 快照中，不写回镜头、提示词或模型配置。
- 任务失败只更新该任务状态，不修改镜头、提示词或已采用视频结果。
- 用户可以对失败任务重试；首版允许复用原失败任务记录，重新提交供应商任务并覆盖该记录的任务状态、供应商任务 ID、失败原因和结果字段。

### 12.3 结果采用与过期

- 同一镜头可以有多个 `succeeded` 视频结果。
- 用户采用某个结果时，该镜头其他视频结果的 `adopted` 自动设为 false。
- 已采用结果应进入后期准备和制作包导出上下文。
- 采用或取消采用视频结果只影响镜头级视频素材采用状态，不触发制作包或其他下游内容标记为需要检查。
- 镜头核心字段、视频提示词或参考素材变化后，已采用视频结果显示“可能过期”提示。
- 过期提示不删除历史结果，也不阻止用户继续导出，但导出前应列为风险警告。

## 13. 状态与下游门槛

### 13.1 镜头状态

- `draft`：正在编辑或来源为草稿剧本。
- `pending_review`：内容基本完成，等待人工确认。
- `confirmed`：已确认，可进入后期准备和正式制作包。
- `needs_review`：剧本、参考素材或镜头核心信息变化，需要复核。

### 13.2 分镜整体状态

分镜整体状态根据镜头状态和结构检查结果汇总：

- 存在结构错误时不能确认。
- 存在 `needs_review` 镜头时整体为 `needs_review`。
- 全部镜头已确认且无结构错误时，整体可以确认为 `confirmed`。
- 草稿剧本生成的分镜只能保持草稿或待确认，不能作为正式制作包输入。
- 正式制作包要求全部镜头无结构错误；一致性警告可以带警告导出。

### 13.3 状态传播

- 来源剧本版本变化后，分镜标记为需要检查。
- 镜头或提示词发生实质变化后，后期准备和制作包标记为需要检查。
- 视频结果采用、取消采用或过期状态变化不触发制作包需要检查；制作包导出时读取当前采用结果并展示过期风险。
- 仅变更展示编号不触发下游需要检查。

## 14. 候选版本与保留规则

- 单场生成和单镜头重新生成都必须先产生候选版本。
- 候选采用前不得更新正式镜头。
- 采用单场候选只替换目标场次的镜头集合。
- 采用单镜头候选只替换目标镜头内容，并保留稳定镜头 ID。
- 范围外镜头不得改变。
- 已采用生成记录永久保留。
- 未采用候选按单集最多保留最近 20 个，超出后清理最旧未采用候选。

## 15. 一致性与结构检查

结构错误：

- 缺少有效来源场次。
- 来源场次已删除且未处理。
- 缺少镜头必填字段。
- 镜头时长小于等于 0。
- 镜头排序冲突或重复。

一致性警告：

- 剧本对白或旁白未被任何镜头覆盖。
- 镜头制作文本与来源剧本存在差异。
- 主要角色缺少已确认参考图。
- 人物、服装、道具或场景连续性风险。
- 视频提示词需要更新。
- 已采用视频结果可能过期。
- 视频生成任务失败或镜头缺少已采用视频结果。
- 场次或整集时长偏差超过 10%。

## 16. 交互要求

### 16.1 页面结构

- 顶部展示集数、来源剧本版本、分镜状态、镜头数量、总时长和主要操作。
- 主区域按场次分组展示镜头。
- 场次标题展示剧本时长、镜头时长和偏差。
- 镜头列表支持紧凑浏览、排序和批量选择。
- 镜头详情展示核心字段、声音、提示词、参考素材、视频生成结果和检查结果。
- 提示词属于镜头详情，不设置独立一级导航。

### 16.2 分镜生成与采用

- “生成整集分镜”按场次编排任务并展示逐场进度。
- 单场生成和单镜头重生成展示候选对比。
- 采用前提示影响范围。
- 生成失败时保留正式镜头，并允许只重试失败场次。

### 16.3 视频生成与采用

- 镜头详情中提供“生成视频”入口，并展示当前采用视频和候选历史。
- 生成视频前展示将使用的提示词、模型配置、参考素材和预计风险。
- 任务运行中展示状态和刷新入口，不阻塞用户继续编辑其他镜头。
- 视频结果支持预览、采用、取消采用和查看输入快照。
- 失败结果展示失败原因和重试入口。
- 用户采用结果前提示该操作会替换当前采用素材，但不会删除历史结果。

### 16.4 编辑保护

- 删除镜头前提示对对白覆盖、时长和下游内容的影响。
- 首版已有视频生成记录的镜头不允许删除，避免丢失或破坏视频生成历史。
- 重新归属场次后自动更新展示编号和时长统计。
- 核心字段变化后明确展示提示词需要更新。
- 核心字段、提示词或参考素材变化后明确展示已采用视频可能过期。
- 切换集数、场次或候选前必须处理未保存修改。

## 17. 旧数据迁移

现有分镜镜头迁移规则：

- 保留原镜头 ID、序号、场景、画面提示词、机位、时长和对白或旁白。
- 尝试根据场景文本和顺序匹配结构化剧本场次。
- 无法匹配时保留镜头并标记为缺少有效来源场次。
- 原画面提示词迁移为自定义通用视频提示词，标记 `customized=true`。
- 无法可靠拆分的机位、运镜和构图保留在机位或迁移备注中。
- 所有迁移镜头状态设为 `needs_review`。
- 迁移不得丢失任何非空原始文本。

## 19. 验收标准

- 系统可以按单场生成候选镜头，并支持整集批量编排。
- 候选采用前不修改正式分镜。
- 每个镜头使用稳定内部 ID 和自动派生展示编号。
- 镜头包含所属场次、景别、主体、画面、动作和大于 0 的时长。
- 用户可以新增、复制、编辑、删除、排序和重新归属镜头。
- 单镜头重新生成不影响范围外镜头。
- 镜头可以追溯剧本内容块并维护可编辑制作文本快照。
- 剧本变化不自动覆盖镜头制作文本。
- 单一视频提示词可编辑，核心字段变化后正确标记需要更新。
- 用户手动修改的提示词不会被自动覆盖。
- 系统显示场次及整集时长和超过 10% 的偏差警告。
- 主要角色缺少参考图时警告但不阻止保存。
- 来源场次删除后镜头保留并阻止确认，直到用户处理。
- 分镜整体状态正确汇总镜头状态和结构错误。
- 正式制作包要求全部镜头无结构错误。
- 视频生成前会校验可用视频模型配置、镜头必填字段和提示词状态。
- 系统可以从单镜头创建视频生成任务，并记录输入快照、模型配置和供应商任务 ID。
- 视频任务支持 queued / running / succeeded / failed / canceled 状态展示。
- 视频生成失败不影响正式分镜、提示词和已有采用结果。
- 同一镜头可以保留多个候选视频结果，并且最多一个结果被标记为 adopted。
- 采用视频结果后，制作包可以引用该镜头采用素材。
- 镜头、提示词或参考素材变化后，已采用视频结果显示可能过期。
- 旧分镜迁移不丢失文本并标记为需要检查。

## 20. 实现决策

- 以 `Storyboard` 作为聚合根，镜头排序、归属和采用通过聚合操作完成。
- 分镜批量生成使用场次级任务编排，允许部分成功和定向重试。
- 提示词生成封装为独立服务，输入平台无关镜头模型，输出单一视频提示词。
- Seedance 等供应商适配封装在视频生成服务中，不污染核心镜头字段。
- 视频生成封装为独立任务服务，输入 `ShotPrompt` 和参考素材，输出 `ShotVideoGeneration` 记录，不反向修改分镜和提示词。
- 视频生成供应商适配器与核心分镜服务分离，避免把供应商任务状态污染到核心镜头字段。
- 剧本来源差异检测封装为独立服务，不自动修改制作文本。
- 时长汇总和 10% 偏差检查封装为纯计算服务。
- 分镜确认校验封装为独立验证器，返回结构化错误和警告。
- 镜头展示编号为派生值，不能作为数据库主键或外部稳定引用。

## 21. 测试决策

测试只验证外部行为和业务合同，不绑定具体 UI 组件或内部函数。

必须覆盖：

- 单场生成、整集编排、部分失败和失败重试。
- 候选预览、采用、放弃和幂等请求。
- 镜头新增、复制、删除、排序、重新归属及展示编号计算。
- 单镜头重新生成的影响范围。
- 必填字段、时长正数和来源场次校验。
- 剧本内容块引用、制作文本快照和差异检测。
- 提示词自定义保护、过期标记和重新生成采用。
- Seedance 适配器输入输出合同。
- 视频生成前置校验、任务创建、幂等提交和状态刷新。
- 视频生成成功、失败、重试和取消的状态流转。
- 视频结果采用、取消采用、同镜头唯一采用约束和过期提示。
- 视频生成失败不覆盖正式分镜、提示词和已采用结果。
- 人物和场景参考素材变化。
- 场次及整集时长汇总和 10% 偏差警告。

- 镜头状态和分镜整体状态汇总。
- 20 条未采用候选上限及正式版本保护。

## 22. 非目标

- 不在本模块生成或保存实际图片文件。
- 不生成完整视频成片。
- 不提供在线视频时间线剪辑器。
- 不保证 Seedance 生成结果质量或接口长期稳定性。
- 不维护最终字幕时间轴。
- 不直接生成剪映工程文件。
- 不要求第一版支持批量一键生成整集所有镜头视频；批量能力可在单镜头闭环稳定后扩展。
