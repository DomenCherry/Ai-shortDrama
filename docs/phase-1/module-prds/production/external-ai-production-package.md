# 模块总览 PRD：外部 AI 视频工具制作包

> 状态：**模块边界已确认，子模块待逐步细化与实现**

## 1. 问题与目标

个人短剧创作者需要把单集故事正文继续加工成外部 AI 图片、AI 视频、配音和剪辑工具能够直接使用的生产资料。当前工作台只能人工维护粗粒度剧本、分镜和文案，缺少结构化生产链路、版本控制和标准化导出。

短期目标是以单集为制作单位，将故事正文转换成可编辑、可复核、可追溯和可导出的制作包，不在系统内完成完整视频生成或在线剪辑。

## 2. 模块边界

```text
单集故事正文
  -> 结构化剧本
  -> 分镜制作（包含镜头 AI 提示词）
  -> 后期准备
  -> 制作包导出
```

| 模块 | 职责 | 详细 PRD |
| --- | --- | --- |
| 结构化剧本 | 将单集故事正文转换成场次和有序剧本内容块 | [structured-script.md](./structured-script.md) |
| 分镜制作 | 将剧本场次拆成镜头，并维护镜头级 AI 素材提示词 | [storyboard-production.md](./storyboard-production.md) |
| 后期准备 | 生成配音、字幕、音效、音乐和剪辑准备资料 | [post-production-prep.md](./post-production-prep.md) |
| 制作包导出 | 校验、组装、版本化并导出单集制作包 | [production-package-export.md](./production-package-export.md) |

人物示意图继续作为独立的上游视觉资产模块，见 [character-image.md](./character-image.md)。

## 3. 统一上下文规则

- 世界观、角色、整体故事大纲、当前分集大纲和单集故事正文是只读上游。
- 短剧制作不能直接修改这些上游内容。
- 如需调整上游，用户必须回到项目资料 / 资产或故事文本模块。
- 每个下游产物必须能够追溯到对应单集和输入版本。
- 上游变化只标记下游为需要检查，不自动删除或覆盖人工内容。

## 4. 统一状态规则

各子模块独立维护状态：

```text
未开始 -> 草稿 -> 待确认 -> 已确认 -> 需要检查
```

- `未开始`：尚无有效内容，可由“无内容记录”派生。
- `草稿`：已有内容，仍在编辑。
- `待确认`：内容基本完成，等待人工复核。
- `已确认`：可作为下游正式输入。
- `需要检查`：上游变化，原内容保留但可能不再一致。

当前产物状态模型仅包含 `draft`、`confirmed`、`needs_review`。实现时需要评估新增 `pending_review`；`未开始`不需要持久化。

状态传播：

- 单集故事正文变化：剧本、分镜、后期准备和制作包需要检查。
- 剧本变化：分镜、后期准备和制作包需要检查。
- 分镜变化：后期准备和制作包需要检查。
- 后期准备变化：制作包需要检查。

## 5. 统一生成与版本规则

- AI 生成先创建候选版本，不能直接覆盖正式内容。
- 用户明确采用候选版本后，候选内容才成为正式内容。
- 局部重新生成不能覆盖无关场次、镜头或人工修改。
- 正式内容和已导出制作包必须记录来源版本。
- 生成失败时保留当前正式内容，并提供可重试的错误信息。

## 6. 外部工具适配原则

- 核心数据保持平台无关。
- 外部工具差异放在导出模板或适配器中。
- 第一版先保证 Markdown、Excel、JSON 和 SRT 可用。
- Seedance 是优先考虑的视频生成适配方向，具体映射在分镜模块细化。
- 剪映是当前明确的剪辑工具；第一阶段通过 SRT、镜头顺序、素材命名和剪辑说明交付，不承诺直接生成剪映工程文件。

## 7. 单集工作台框架

- 顶部：集数切换、单集整体进度、上游风险和当前主要操作。
- 一级导航：剧本、分镜、后期准备、制作包。
- 主编辑区：当前模块的结构化内容和操作。
- 右侧可折叠上下文：分集大纲、正文摘要、角色、世界观和一致性提示。
- 页面保持紧凑、浅色、高信息密度，延续现有工作台组件和交互习惯。

## 8. 单集整体进度

系统根据各子模块状态派生单集进度：

- 剧本未完成。
- 分镜制作中。
- 后期准备中。
- 可以导出。
- 制作包已生成。
- 上游变更，需要重新检查。

## 9. 非目标

- 不在系统内生成完整视频成片。
- 不建设在线视频剪辑器。
- 不自动发布到内容平台。
- 不做复杂团队审片和权限流程。
- 不承诺外部生成工具的输出质量。
- 第一版不支持大量外部平台的深度 API 集成。

## 10. 实施顺序

1. 结构化剧本。
2. 分镜制作和平台无关提示词。
3. 后期准备。
4. 制作包校验、版本与导出。
5. Seedance、剪映等外部工具适配。

## 11. 验收原则

- 四个子模块边界清晰，数据依赖方向单一。
- 用户可以按单集推进完整制作流程。
- 每个模块都支持人工编辑、复核和状态管理。
- 上游变化不会静默覆盖下游内容。
- 导出结果可追溯到对应输入和内容版本。
