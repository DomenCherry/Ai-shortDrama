# 模块 PRD：人物示意图生成

> 状态：**未实现** — 本文档为占位规格，待 AI 生成能力接入后补充详细设计。

## 1. 功能定位

系统根据人物文字设定、人物视觉描述和形象关键词，为主要人物生成示意图，辅助确认角色视觉形象并为后续视频生成提供人物一致性参考素材。

## 2. 输出内容

人物示意图应包含：

- 人物图片生成提示词。
- 人物示意图。
- 图片地址或本地路径。
- 图片生成版本。
- 用户确认状态。

示意图应辅助确认：

- 年龄感。
- 气质。
- 服装。
- 发型。
- 脸部特征。
- 角色风格。
- 与人物设定的一致性。

## 3. 交互要求

- 用户可以为单个人物生成示意图。
- 用户可以重新生成单个人物示意图。
- 用户可以确认当前示意图作为该人物的参考形象。
- 重新生成某个人物示意图时，不应覆盖其他人物图片。
- 已确认的人物示意图应作为后续视频生成的人物一致性参考素材。

## 4. 数据对象

### 4.1 CharacterImage

表示人物示意图。

字段建议：

- project_id
- character_id
- prompt
- image_url
- local_path
- version
- status
- confirmed_at
- created_at

状态建议：

- draft
- generated
- confirmed
- rejected

## 5. 用户故事

23. 作为个人短剧创作者，我想为主要人物生成示意图，以便确认角色视觉形象。
24. 作为个人短剧创作者，我想重新生成单个人物示意图，以便调整角色外观。
25. 作为个人短剧创作者，我想确认人物示意图，以便作为后续视频生成的一致性参考。

## 6. 验收标准

- 生成人物设定后，系统可以为主要人物生成示意图。
- 用户可以确认或重新生成某个人物示意图。
- 用户确认人物示意图后，该图片应在导出内容中作为人物参考信息出现。
- 人物示意图生成不代表第一期支持完整视频生成。
