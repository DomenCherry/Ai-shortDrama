# 详细设计：模型 API 配置与连通性测试

## 1. 功能定位

“模型 API 配置与连通性测试”是第一期的基础配置能力。它负责让用户配置自己的文本生成模型 API 和图片生成模型 API，并在使用前通过手动测试确认接口是否可用。

配置中心应以用户自定义模型为核心，不绑定单一供应商。系统可以提供常用供应商预设来减少填写成本，但用户仍应能够手动配置其他兼容或非兼容供应商。

该功能不是一个创作模块，但它是后续 AI 生成能力的前置条件：

- 文本生成模型用于生成选题策划、整体故事大纲、人物设定、分集大纲、单集剧本和改写内容。
- 图片生成模型用于生成人物示意图、角色三视图等图片生成任务。

## 2. 功能目标

用户完成该功能后，系统应知道应该调用哪个文本模型和哪个图片模型，并能确认接口处于可用状态。

必须达成：

- 用户可以保存文本生成模型配置。
- 用户可以保存图片生成模型配置。
- 用户可以通过供应商预设快速创建图片模型配置。
- 用户可以通过自定义配置接入其他图片模型供应商。
- 用户可以分别测试文本模型和图片模型。
- 系统可以展示测试成功或失败状态。
- 测试失败时，系统可以给出可理解的失败原因。
- 未配置或测试不可用时，系统阻止对应生成任务。
- API Key 不在普通页面明文展示，也不进入 Markdown 导出。

## 3. 页面设计

### 3.1 配置入口

建议在应用左侧导航或顶部导航中增加“设置”入口。

设置页包含：

- 文本生成模型配置。
- 图片生成模型配置。

图片模型配置区应支持两种配置方式：

- 供应商预设：系统提供默认 API 地址、接口路径和能力说明。
- 自定义配置：用户自行填写供应商名称、API 地址、模型名称和图片能力。

第一期只需要单用户配置，不需要团队级配置、成员权限或多工作区配置。

### 3.2 文本生成模型配置区

用途：

- 配置脚本文案相关的文本生成模型。
- 测试文本生成接口是否可用。

字段：

- 供应商名称。
- API Base URL。
- API Key。
- 模型名称。
- 备注。

核心操作：

- 保存配置。
- 测试连接。
- 清空未保存修改。

状态展示：

- 未配置。
- 已配置，未测试。
- 测试成功。
- 测试失败。
- 最近测试时间。
- 最近失败原因。

### 3.3 图片生成模型配置区

用途：

- 配置人物示意图生成模型。
- 测试图片生成接口是否可用。

字段：

- 配置方式。
- 供应商名称。
- 供应商预设。
- API Base URL。
- API Key。
- 模型名称。
- 图片尺寸。
- 是否支持参考图输入。
- 备注。

第一期建议内置的图片供应商预设：

| 预设 | 默认供应商名称 | 默认 API Base URL | 默认接口路径 | 参考图输入 | 主要用途 |
| --- | --- | --- | --- | --- | --- |
| `volcengine_seedream` | 火山方舟 Seedream | `https://ark.cn-beijing.volces.com/api/v3` | `/images/generations` | 支持 | 角色示意图、角色三视图 |

火山方舟 Seedream 只是第一批预设之一。后续可继续增加阿里百炼、腾讯混元、OpenAI-compatible、SiliconFlow 等预设；自定义配置始终保留。

图片尺寸第一期可以使用文本输入或简单选项，例如：

- 1024x1024。
- 1024x1536。
- 1536x1024。

核心操作：

- 保存配置。
- 测试连接。
- 清空未保存修改。

状态展示：

- 未配置。
- 已配置，未测试。
- 测试成功。
- 测试失败。
- 最近测试时间。
- 最近失败原因。

## 4. 字段设计

### 4.1 ModelApiConfig

| 字段 | 类型 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| id | string | 是 | 自动生成 | 配置唯一标识 |
| config_type | string | 是 | 无 | `text` 或 `image` |
| provider_mode | string | 是 | custom | `preset` 或 `custom` |
| provider_preset | string | 否 | 无 | 供应商预设标识，例如 `volcengine_seedream` |
| provider_name | string | 是 | 无 | 供应商名称 |
| api_base_url | string | 是 | 无 | API 地址 |
| api_key_secret | string | 是 | 无 | 安全保存后的 API Key |
| model_name | string | 是 | 无 | 模型名称 |
| image_size | string | 否 | 1024x1024 | 图片生成尺寸，仅图片配置使用 |
| endpoint_path | string | 否 | `/images/generations` | 图片生成接口路径，仅图片配置使用 |
| supports_reference_image | boolean | 否 | false | 是否支持参考图输入，仅图片配置使用 |
| remark | string | 否 | 无 | 备注 |
| enabled | boolean | 是 | true | 是否启用为当前默认配置 |
| last_test_status | string | 是 | untested | 最近测试状态 |
| last_tested_at | datetime | 否 | 无 | 最近测试时间 |
| last_test_error | string | 否 | 无 | 最近失败原因 |
| created_at | datetime | 是 | 自动生成 | 创建时间 |
| updated_at | datetime | 是 | 自动更新 | 更新时间 |

### 4.2 last_test_status 状态

可选状态：

- `untested`：已保存但未测试。
- `success`：最近一次测试成功。
- `failed`：最近一次测试失败。

### 4.3 ModelApiTestLog

| 字段 | 类型 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| id | string | 是 | 自动生成 | 测试记录唯一标识 |
| config_id | string | 是 | 无 | 关联配置 |
| config_type | string | 是 | 无 | `text` 或 `image` |
| request_summary | string | 否 | 无 | 脱敏后的测试请求摘要 |
| success | boolean | 是 | 无 | 是否成功 |
| response_summary | string | 否 | 无 | 脱敏后的响应摘要 |
| error_message | string | 否 | 无 | 失败原因 |
| latency_ms | integer | 否 | 无 | 接口耗时 |
| tested_at | datetime | 是 | 自动生成 | 测试时间 |

## 5. 校验规则

### 5.1 通用校验

保存配置时必须校验：

- 供应商名称不能为空。
- API Base URL 不能为空。
- API Key 不能为空。
- 模型名称不能为空。

API Base URL 应至少满足：

- 以 `http://` 或 `https://` 开头。
- 不能包含明显空格。

API Key 展示规则：

- 已保存的 API Key 默认脱敏展示。
- 用户无法直接查看完整 API Key。
- 用户可以重新输入新的 API Key 覆盖旧值。

### 5.2 图片配置校验

图片尺寸不能为空。

第一期不强制校验所有供应商的尺寸合法性，只需要保存用户输入或选项值。具体尺寸是否被供应商支持，由连通性测试返回结果判断。

当用户选择供应商预设时：

- `provider_preset` 必须是系统已支持的预设标识。
- 系统应自动填充默认 API Base URL、接口路径和参考图能力。
- 用户可以修改模型名称、图片尺寸和备注。

当用户选择自定义配置时：

- 供应商名称、API Base URL、API Key、模型名称仍由用户手动填写。
- 是否支持参考图输入由用户配置或后续测试结果确认。
- 系统不假设自定义供应商一定兼容某个固定协议。

## 6. 连通性测试设计

### 6.1 文本模型测试

测试输入建议：

```text
请返回一句不超过 10 个字的中文短句：接口可用。
```

成功判断：

- 接口返回成功状态。
- 响应中包含可解析的文本内容。
- 文本内容不为空。

失败判断：

- 网络不可达。
- API Key 无效。
- 模型名称不存在。
- 响应超时。
- 响应格式无法解析。
- 额度不足或权限不足。

### 6.2 图片模型测试

测试提示词建议：

```text
一张简单的角色头像示意图，年轻女性，现代都市风格，干净背景。
```

成功判断：

- 接口返回成功状态。
- 响应中包含图片 URL、图片文件、本地路径或可解析的图片结果。
- 图片结果可以被系统记录。
- 对声明支持参考图输入的图片配置，后续角色三视图生成可以携带已上传参考图；第一期连通性测试可以先使用轻量文生图请求验证基础可用性。

失败判断：

- 网络不可达。
- API Key 无效。
- 模型名称不存在。
- 图片尺寸不支持。
- 供应商预设和实际接口协议不匹配。
- 参考图输入参数不支持。
- 响应超时。
- 响应格式无法解析。
- 额度不足或权限不足。

### 6.3 测试结果记录

每次测试后都应更新：

- `last_test_status`。
- `last_tested_at`。
- `last_test_error`。

同时新增一条 `ModelApiTestLog`。

## 7. 错误提示

| 场景 | 提示文案 |
| --- | --- |
| 供应商名称为空 | 请填写供应商名称 |
| API Base URL 为空 | 请填写 API 地址 |
| API Base URL 格式错误 | API 地址必须以 http:// 或 https:// 开头 |
| API Key 为空 | 请填写 API Key |
| 模型名称为空 | 请填写模型名称 |
| 供应商预设不可用 | 该供应商预设暂不可用，请选择自定义配置 |
| 文本模型未配置 | 请先配置文本生成模型 API |
| 图片模型未配置 | 请先配置图片生成模型 API |
| 文本模型未测试成功 | 文本生成模型暂不可用，请先完成接口测试 |
| 图片模型未测试成功 | 图片生成模型暂不可用，请先完成接口测试 |
| API Key 错误 | API Key 无效，请检查后重试 |
| 模型不存在 | 模型名称不可用，请检查模型配置 |
| 网络不可达 | 接口无法访问，请检查 API 地址或网络连接 |
| 响应格式异常 | 接口响应格式无法解析，请检查供应商配置 |
| 额度不足 | 接口额度不足或无调用权限 |
| 参考图输入不支持 | 当前图片模型不支持参考图输入，请更换模型或关闭参考图能力 |

## 8. 交互流程

### 8.1 保存文本模型配置

```text
用户进入设置页
 -> 填写文本模型配置
 -> 点击保存
 -> 系统校验字段
 -> 保存成功
 -> 状态显示为已配置，未测试
```

### 8.2 测试文本模型

```text
用户点击测试连接
 -> 系统发送轻量文本测试请求
 -> 接口返回可解析文本
 -> 系统记录测试成功
 -> 状态显示为测试成功
```

### 8.3 测试图片模型

```text
用户点击测试连接
 -> 系统发送轻量图片测试请求
 -> 接口返回可解析图片结果
 -> 系统记录测试成功
 -> 状态显示为测试成功
```

### 8.4 保存火山方舟 Seedream 预设图片配置

```text
用户进入设置页
 -> 图片模型配置选择供应商预设
 -> 选择火山方舟 Seedream
 -> 系统自动填充默认 API Base URL 和接口路径
 -> 用户填写 API Key、模型名称和图片尺寸
 -> 点击保存
 -> 系统保存为当前启用图片模型配置
```

### 8.5 测试失败

```text
用户点击测试连接
 -> 接口调用失败或响应不可解析
 -> 系统记录测试失败
 -> 展示失败原因
 -> 用户修改配置后再次测试
```

## 9. 生成任务拦截规则

文本生成任务包括：

- 选题策划生成。
- 整体故事大纲生成。
- 人物设定生成。
- 分集大纲生成。
- 单集剧本生成。
- 文本改写。

执行这些任务前必须满足：

- 存在启用的文本模型配置。
- 文本模型最近测试状态为 `success`。

图片生成任务包括：

- 人物示意图生成。
- 人物示意图重新生成。
- 角色三视图生成。
- 角色三视图重新生成。

执行这些任务前必须满足：

- 存在启用的图片模型配置。
- 图片模型最近测试状态为 `success`。

如果生成任务需要上传参考图参与生成，还应满足：

- 当前图片模型配置声明支持参考图输入。
- 当前角色已上传可读取的参考图。

如果不满足条件，系统应阻止生成，并引导用户进入设置页。

## 10. 安全要求

- API Key 不写入 Markdown 导出。
- API Key 不在列表、卡片、普通文本中明文展示。
- 测试日志中不保存完整 API Key。
- 错误日志中不展示完整 API Key。
- 如果后续实现为 Web 应用，API Key 不应暴露到前端可读取的持久化存储中。

## 11. 验收用例

### 11.1 保存文本模型配置

输入：

- 供应商名称：自定义文本模型。
- API Base URL：`https://api.example.com/v1`。
- API Key：有效密钥。
- 模型名称：`text-model`。

预期：

- 配置保存成功。
- API Key 脱敏展示。
- 状态为已配置，未测试。

### 11.2 文本模型测试成功

前置条件：

- 已保存可用文本模型配置。

预期：

- 点击测试连接后，系统调用文本接口。
- 测试成功。
- 显示最近测试时间。
- 文本生成任务可用。

### 11.3 文本模型测试失败

输入：

- API Key 错误或模型名称错误。

预期：

- 测试失败。
- 显示明确失败原因。
- 文本生成任务不可用。

### 11.4 保存图片模型配置

输入：

- 供应商名称：自定义图片模型。
- API Base URL：`https://api.example.com/v1`。
- API Key：有效密钥。
- 模型名称：`image-model`。
- 图片尺寸：`1024x1024`。

预期：

- 配置保存成功。
- API Key 脱敏展示。
- 状态为已配置，未测试。

### 11.5 保存火山方舟 Seedream 图片模型预设

输入：

- 配置方式：供应商预设。
- 供应商预设：火山方舟 Seedream。
- API Key：有效火山方舟密钥。
- 模型名称：用户实际开通的 Seedream 模型。
- 图片尺寸：`1024x1024`。

预期：

- 系统自动填充 API Base URL：`https://ark.cn-beijing.volces.com/api/v3`。
- 系统记录接口路径：`/images/generations`。
- 系统记录该配置支持参考图输入。
- 配置保存成功，状态为已配置，未测试。

### 11.6 图片模型测试成功

前置条件：

- 已保存可用图片模型配置。

预期：

- 点击测试连接后，系统调用图片接口。
- 测试成功。
- 显示最近测试时间。
- 人物示意图和角色三视图生成任务可用。

### 11.7 未配置文本模型时生成选题

前置条件：

- 不存在可用文本模型配置。

预期：

- 用户点击生成选题策划时，系统阻止生成。
- 显示提示：请先配置文本生成模型 API。

### 11.8 未配置图片模型时生成人物示意图

前置条件：

- 不存在可用图片模型配置。

预期：

- 用户点击生成人物示意图时，系统阻止生成。
- 显示提示：请先配置图片生成模型 API。

### 11.9 参考图三视图生成前置校验

前置条件：

- 已保存图片模型配置。
- 图片模型最近测试状态为 `success`。
- 角色已上传参考图。

预期：

- 如果图片模型支持参考图输入，系统允许基于角色文字设定和参考图生成三视图。
- 如果图片模型不支持参考图输入，系统阻止参考图参与生成，并提示更换支持参考图的图片模型。

### 11.10 Markdown 导出不包含密钥

前置条件：

- 已保存文本模型和图片模型配置。

预期：

- 导出的 Markdown 中不包含 API Key。
- 导出的 Markdown 不包含任何密钥明文。

## 12. 实现建议

建议优先级：

1. 设置页入口。
2. 文本模型配置保存。
3. 图片模型自定义配置保存。
4. 图片模型供应商预设选择。
5. 火山方舟 Seedream 预设。
6. 文本模型测试按钮。
7. 图片模型测试按钮。
8. 测试状态记录。
9. 生成任务前置拦截。

第一期暂不做：

- 完整多供应商模板库。
- 多个文本模型之间的自动路由。
- 多个图片模型之间的自动路由。
- 团队级 API Key 管理。
- 用量统计和费用分析。
- 自动定时健康检查。
