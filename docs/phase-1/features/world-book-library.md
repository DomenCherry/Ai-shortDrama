# 功能说明 Spec：世界观库

## 1. 功能定位

世界观库用于独立管理可复用的故事世界设定。

它解决的问题是：用户可能会反复创作同一题材、同一系列或同一世界观下的多个短剧项目，不希望每次都重新输入时代背景、世界规则、组织关系、地点设定和风格约束。

世界观库只管理资产库中的原始世界观内容。世界观被加载到项目后，会生成项目内快照副本；项目内快照的编辑和引用规则见 [创作资产库](./creative-asset-library.md)。

## 2. 用户目标

- 用户可以创建一个可复用世界观。
- 用户可以把大型世界观拆成多个结构化条目，便于后续生成时引用。
- 用户可以查看、编辑、停用或归档世界观。
- 用户可以在项目创建或项目工作台中选择世界观加载到项目。
- 用户可以知道某个世界观被哪些项目使用过。

## 3. 功能范围

第一期需要支持：

- 世界观列表。
- 世界观新建。
- 世界观详情查看。
- 世界观基础信息编辑。
- 世界观条目管理。
- 世界观状态管理。
- 世界观被项目加载前的预览。

第一期暂不支持：

- 多人共享世界观。
- 世界观市场或模板商城。
- 复杂关键词自动触发规则。
- 自动把资产库新版本同步到已加载项目。
- 世界观版本差异对比。

## 4. 页面结构

### 4.1 世界观列表页

列表页用于查看和管理已有世界观。

展示字段：

- 世界观名称。
- 题材类型。
- 时代背景摘要。
- 风格标签。
- 条目数量。
- 状态。
- 版本。
- 更新时间。

基础操作：

- 新建世界观。
- 进入世界观详情。
- 搜索世界观名称。
- 按题材、状态筛选。
- 归档世界观。

空状态：

- 当没有世界观时，展示创建入口。
- 空状态文案应引导用户沉淀可复用设定，而不是强调复杂配置。

### 4.2 世界观详情页

详情页用于维护一个世界观的完整内容。

页面区域：

- 基础信息区。
- 核心设定区。
- 世界观条目区。
- 使用记录区。
- 操作区。

基础操作：

- 保存修改。
- 新增条目。
- 编辑条目。
- 删除或停用条目。
- 归档世界观。
- 加载到项目。

### 4.3 世界观条目编辑区

世界观条目用于把大段设定拆成可引用的信息块。

建议条目类型：

- 世界规则。
- 地点。
- 组织。
- 阶层关系。
- 历史事件。
- 特殊物品。
- 禁忌或限制。
- 风格约束。
- 其他。

条目应支持排序或优先级。第一期不需要实现复杂触发算法，但需要保留关键词和适用范围，方便后续做上下文选择。

## 5. 字段设计

### 5.1 WorldBook

表示一个可复用世界观资产。

字段建议：

- id：唯一标识。
- name：世界观名称。
- genre：题材类型。
- era_background：时代背景。
- world_rules：核心世界规则。
- organizations：主要组织。
- locations：主要地点。
- social_structure：社会结构或势力关系。
- taboo_or_constraints：禁忌、限制或不可违反的设定。
- tone_style：整体风格。
- summary：短摘要，用于列表和项目加载预览。
- version：版本号。
- status：状态。
- created_at：创建时间。
- updated_at：更新时间。

### 5.2 WorldEntry

表示世界观中的一个可引用条目。

字段建议：

- id：唯一标识。
- world_book_id：所属世界观。
- title：条目标题。
- entry_type：条目类型。
- keywords：关键词。
- content：条目正文。
- applicable_scope：适用范围，例如全局、特定角色、特定地点、特定剧情阶段。
- priority：优先级。
- status：状态。
- created_at：创建时间。
- updated_at：更新时间。

## 6. 状态规则

世界观状态建议：

- draft：草稿。
- active：可加载。
- archived：已归档。

条目状态建议：

- active：可被加载和引用。
- disabled：暂不参与加载和引用。

规则：

- 只有 `active` 世界观可以被加载到项目。
- 已归档世界观不从历史项目中删除。
- 世界观内容发生影响生成上下文的修改时，应提升版本号。
- 删除已被项目加载过的世界观风险较高，第一期建议使用归档代替硬删除。

## 7. 项目加载规则

用户在项目创建或项目工作台中选择世界观后，系统应把当前世界观内容复制为项目内快照。

快照内容应包括：

- 世界观基础信息。
- 当前启用的世界观条目。
- 来源世界观 ID。
- 来源世界观版本。
- 加载时间。

加载后：

- 项目生成任务读取项目内快照。
- 用户在项目内修改世界观快照，不影响世界观库原始内容。
- 用户在世界观库修改原始内容，不自动覆盖项目内快照。

## 8. 生成引用规则

世界观库本身不直接参与生成。生成任务应通过项目内快照读取世界观内容。

当项目已加载世界观时：

- 选题策划应参考世界观题材、风格和核心规则。
- 故事大纲应遵守世界规则、组织关系和主要地点设定。
- 人物设定应符合世界观中的阶层、组织、禁忌和时代背景。
- 分集大纲和剧本应避免违反已加载世界观规则。

当项目未加载世界观时：

- 系统仍可按原有创意输入生成。
- 用户可以后续再加载世界观，但需要提示已有内容可能需要重新校准。

## 9. 验收标准

- 用户可以创建世界观。
- 用户可以编辑世界观基础信息。
- 用户可以新增、编辑、停用世界观条目。
- 用户可以在列表中搜索和筛选世界观。
- 用户可以把 `active` 世界观加载到项目。
- 加载到项目后会生成项目内快照，并保留来源 ID 和来源版本。
- 项目内修改世界观快照不会改变世界观库原始内容。
- 世界观库原始内容更新不会自动覆盖项目内快照。
- 已归档世界观不再作为新项目可选项，但历史项目来源仍可追踪。

## 10. 后续扩展

- 支持世界观版本差异对比。
- 支持按关键词、角色、地点和剧情阶段动态选择条目。
- 支持从项目内快照另存为新世界观。
- 支持世界观模板。
- 支持世界观之间的系列关系。
