# 第一期后端接口 Spec 索引

后端接口 spec 用于在实现 FastAPI 路由、Pydantic schema、service 业务规则和数据库迁移前，明确接口合同、校验规则、错误提示和前端依赖。

后端接口 spec 按影响范围创建，不要求每个功能都单独创建。如果需求只影响页面布局、文案、样式或纯前端交互，可只更新前端页面 spec 或直接修复代码。

## 编写约定

- 后端接口 spec 不替代模块 PRD。
- 后端接口 spec 必须和前端页面 spec 的 API 依赖保持一致。
- 涉及数据库结构、接口路径、请求体、响应体、错误提示或状态传播时，应同步更新对应模块 PRD 和前端 spec。
- 影响模型调用、API Key 安全、软删除、快照隔离、版本保留等后端业务边界时，必须补充后端接口 spec。
- 前端 spec 中的 API 依赖表只说明页面调用关系；接口合同、数据库写入边界和错误规则以后端接口 spec 为准。
