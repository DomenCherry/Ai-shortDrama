# AI 短剧制作系统项目分期规划

## 1. 项目总目标

本项目的核心目标是：帮助个人创作者独立完成短剧内容生产，并将作品发布到线上平台。

因此，系统的第一优先级不是做成一个通用 SaaS 平台，也不是一开始就追求全自动生成完整视频，而是先帮助创作者完成一条真实可用的短剧生产闭环：

```text
想法 -> 选题 -> 大纲 -> 剧本 -> 分镜 -> 素材准备 -> 配音/字幕 -> 剪辑辅助 -> 发布
```

项目分期应围绕“能不能实际产出并发布短剧”来设计。每一期都应该交付一个可用能力，而不是只完成底层技术。

## 2. 分期原则

### 2.1 先完成个人创作闭环

第一阶段不追求团队协作、复杂权限、商业化、数据看板等平台能力。先确保一个人可以通过系统把短剧从创意推进到可发布内容。

### 2.2 先做确定性强的环节

剧本、分镜、提示词、配音文本、字幕和剪辑清单的确定性较高，适合优先建设。镜头级文生视频可以在分镜闭环后接入，但完整成片生成和自动剪辑成本高、质量波动大，应放在后续阶段逐步推进。

### 2.3 每期都能产出内容

每一期结束后，都应该能帮助创作者产出更完整的短剧材料。理想状态是：从第一期开始就能辅助真实项目，而不是等所有系统建完后才可用。

### 2.4 先服务自己，再抽象成产品

早期系统可以围绕个人创作者工作流优化。等实际制作过多部短剧后，再把稳定流程抽象成模板、工具和产品能力。

## 3. 第一期：短剧策划、剧本与镜头视频工作台

### 3.1 阶段目标

完成从创意到完整剧本、分镜和镜头级视频素材候选的生产能力，帮助创作者快速确定题材、人物、分集结构、单集剧本和可进入剪辑准备的镜头素材。

这一期完成后，用户应该可以输入一个短剧想法，并得到一套可以继续打磨的短剧项目文本资料、分镜提示词和镜头级视频生成结果。

### 3.2 核心功能

- 创建短剧项目。
- 配置目标平台、题材、集数、单集时长、目标受众和风格。
- 生成短剧选题方向。
- 生成剧名、卖点、目标用户画像和核心爽点。
- 生成人物设定，包括主角、反派、配角、人物关系和隐藏秘密。
- 生成完整分集大纲。
- 生成单集剧本。
- 生成或维护结构化分镜和镜头级视频提示词。
- 按镜头调用文生视频 API 并管理候选视频结果。
- 支持对剧本进行改写，例如更爽、更虐、更悬疑、更口语化、更适合短视频平台。
- 支持将项目文本导出为 Markdown。

### 3.3 交付结果

- 可以创建和保存一个短剧项目。
- 可以生成一部短剧的完整策划资料。
- 可以生成至少一集完整剧本。
- 可以为至少一个镜头生成并采用视频素材候选。
- 可以导出项目文本资料。

### 3.4 不做内容

- 不做一键完整视频成片。
- 不做复杂分镜图。
- 不做在线剪辑器。
- 不做账号体系和团队协作。
- 不做自动发布。

## 4. 第二期：制作资料增强与批量化工作台

### 4.1 阶段目标

在第一期分镜和镜头级视频闭环基础上，增强批量化制作资料、素材清单和跨集一致性管理，帮助创作者更高效地组织整部短剧的制作过程。

这一期完成后，系统应能够把单集和跨集制作资料整理成更完整的清单、批量任务和可交付制作包。

### 4.2 核心功能

- 跨集汇总场景清单、角色出场清单、道具清单和素材清单。
- 批量检查分镜、提示词、视频结果和参考素材缺失。
- 批量重试失败的视频生成任务。
- 批量导出分镜表格、提示词表和素材清单。
- 管理跨集人物、服装、道具和场景连续性提示。
- 支持制作包的更多格式和模板。

### 4.3 交付结果

- 创作者可以按单集和整部短剧查看制作资料完整度。
- 创作者可以批量整理失败任务、缺失素材和待确认镜头。
- 创作者可以拿到更标准化的制作资料包。

### 4.4 不做内容

- 不直接承诺生成稳定成片。
- 不做复杂的 3D 分镜。
- 不做多人协作审片流程。

## 5. 第三期：配音、字幕与剪辑辅助

### 5.1 阶段目标

补齐短剧发布前的音频和剪辑准备能力，让创作者可以更快完成后期制作。

这一期完成后，系统应能生成配音脚本、字幕文件、剪辑节奏建议和基础发布物料。

### 5.2 核心功能

- 生成多角色配音脚本。
- 标注角色、情绪、语速和语气。
- 生成字幕文本。
- 支持导出 SRT 字幕文件。
- 生成 BGM 和音效建议。
- 生成剪辑节奏建议，包括开头钩子、转场点、情绪点和结尾悬念。
- 生成标题、简介、标签和封面文案。

### 5.3 交付结果

- 可以把剧本转化为可配音、可剪辑、可发布的辅助材料。
- 创作者可以基于导出的资料在剪辑软件中完成作品。
- 系统开始覆盖从创意到发布准备的完整链路。

### 5.4 不做内容

- 不做完整专业级剪辑软件。
- 不做自动上传平台。
- 不做复杂音频混音工作站。

## 6. 第四期：AI 视觉资产扩展与素材管理增强

### 6.1 阶段目标

在已有剧本、分镜、提示词和镜头级视频生成闭环的基础上，扩展更多视觉资产生成和素材管理能力，逐步提高自动化制作程度。

这一期的重点不是“一键生成整部短剧”，而是让创作者更系统地生成、整理和复用角色、场景、封面和镜头素材。

### 6.2 核心功能

- 生成角色形象参考图。
- 生成场景参考图。
- 生成封面图。
- 按镜头调用 AI 图片生成工具。
- 增强镜头视频生成结果的批量管理、下载、替换和版本对比。
- 标记可用素材、需重做素材和已采用素材。
- 支持素材下载和整理。

### 6.3 交付结果

- 创作者可以从系统中生成和管理短剧视觉素材。
- 分镜提示词可以直接进入图像生成和已接入的视频生成管理流程。
- 系统从“前期生产工具”升级为“素材生产工具”。

### 6.4 不做内容

- 不要求所有视频镜头都能一次生成成功。
- 不做复杂角色一致性训练系统。
- 不做完整自动剪辑成片。

## 7. 第五期：成片组装与发布闭环

### 7.1 阶段目标

把前面生成的剧本、分镜、素材、配音、字幕和发布文案整合起来，形成更完整的短剧发布闭环。

这一期完成后，创作者应能在系统中更系统地管理从制作到发布的全过程。

### 7.2 核心功能

- 管理每集制作状态。
- 汇总视频素材、音频素材、字幕文件和封面图。
- 生成剪辑工程清单或粗剪方案。
- 支持基础成片预览。
- 支持导出发布包。
- 记录发布时间、平台、标题、封面和链接。
- 手动录入播放量、完播率、点赞、收藏、评论等数据。
- 基于发布数据反推选题和剧本优化建议。

### 7.3 交付结果

- 创作者可以管理一部短剧从制作到发布后的全流程。
- 系统可以开始沉淀真实发布数据。
- 后续可以基于数据优化创作策略。

### 7.4 不做内容

- 不强制自动发布到平台。
- 不做复杂广告投放系统。
- 不做大型团队工作流。

## 8. 第六期：产品化与规模化

### 8.1 阶段目标

在个人创作流程跑通、多部短剧验证后，再将系统逐步产品化，支持更多创作者或小团队使用。

### 8.2 核心功能

- 用户账号体系。
- 项目权限管理。
- 团队协作。
- 模板市场或模板库。
- 多项目批量管理。
- 计费和额度系统。
- 内容审核和合规检查。
- 更完整的数据分析。
- 更多模型和工具接入。

### 8.3 交付结果

- 系统从个人创作工具升级为可面向外部用户的产品。
- 支持多人、多项目、多工作流协作。
- 具备商业化基础。

## 9. 推荐执行顺序

推荐先按以下顺序推进：

```text
第一期：短剧策划、剧本与镜头视频工作台
第二期：制作资料增强与批量化工作台
第三期：配音、字幕与剪辑辅助
第四期：AI 视觉资产扩展与素材管理增强
第五期：成片组装与发布闭环
第六期：产品化与规模化
```

其中，前三期应作为第一阶段大目标。完成前三期后，创作者已经可以使用系统完成从创意到镜头素材、配音字幕和发布准备的完整前期流程。

第四期继续扩展 AI 视觉资产、素材整理和批量管理，适合在前期流程稳定后再推进。

第五期解决真实发布管理和数据回流。

第六期才考虑把个人工具扩展成面向更多用户的产品。

## 10. 当前最优先任务

当前最优先的是完成第一期从策划、剧本、分镜到镜头级视频结果管理的最小闭环：

```text
短剧策划、剧本与镜头视频工作台
```

第一期最小可用版本可以只包含：

- 项目创建。
- 创意输入。
- 选题策划生成。
- 人物设定生成。
- 分集大纲生成。
- 单集剧本生成。
- Markdown 导出。

只要这一期跑通，就可以开始真实创作第一部短剧，并在实际使用中继续修正后续功能设计。
