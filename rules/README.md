# 短剧创作规则

`rules/` 存放用户侧短剧创作规则，用于补充 `skills/short-drama-creator/SKILL.md`。

分工原则：

- `skills/short-drama-creator/SKILL.md`：定义何时使用短剧创作能力、整体流程和规则路由。
- `rules/*.md`：定义具体模块的产出结构、质量要求和检查点。

## 当前规则

- `topic-planning-rule.md`：选题策划规则。
- `story-outline-rule.md`：整体故事大纲与剧情脉络规则。
- `character-design-rule.md`：人物设定规则。
- `character-image-rule.md`：人物示意图与图片提示词规则。
- `episode-outline-rule.md`：分集大纲规则。
- `script-writing-rule.md`：单集剧本规则。

## 使用原则

- 用户已有手动修改内容时，以用户修改为准。
- 下游内容必须引用上游已确认内容。
- 生成结果应可编辑、可复用、可导出。
- 短剧总时长不超过 240 分钟，单集时长不超过 2 分钟。
