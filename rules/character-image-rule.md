# 人物示意图规则

## 使用场景

当主要人物文字设定已生成或已确认后，使用本规则生成用于图片模型的人物示意图提示词。

人物示意图用于确认角色形象，并作为后续视频生成的人物一致性参考素材。

## 输入要求

优先使用：

- 已确认的人物设定。
- 人物视觉描述。
- 形象关键词。
- 项目整体风格。
- 用户对年龄、气质、服装、发型、脸部特征的修改意见。

## 输出结构

每个人物包含：

- 人物视觉描述。
- 形象关键词。
- 图片生成提示词。
- 负向提示词或避免项。
- 用于确认的检查点。

## 提示词要求

提示词应明确：

- 年龄段。
- 性别表达。
- 气质。
- 发型。
- 服装。
- 脸部特征。
- 角色风格。
- 画面类型，例如角色半身像、正面、干净背景。

## 质量要求

- 同一人物的提示词应保持稳定，避免每次重新生成时改变核心外观。
- 不同人物之间要有可区分的视觉特征。
- 不生成场景图、分镜图或视频提示词。
- 图片确认后，应保留该版本作为后续参考素材。
