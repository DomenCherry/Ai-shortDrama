# 单集剧本规则

## 使用场景

当某一集分集大纲已确认后，使用本规则生成单集剧本。

剧本必须基于对应分集大纲、整体故事大纲和人物设定。

## 输入要求

优先使用：

- 指定集数的分集大纲。
- 整体故事大纲。
- 人物设定。
- 用户对对白、节奏、风格的补充要求。

## 输出结构

单集剧本包含：

- 集数标题。
- 场景编号。
- 场景地点。
- 场景时间。
- 出场人物。
- 动作描写。
- 人物对白。
- 情绪提示。
- 结尾悬念。
- 预计时长。

## 质量要求

- 开头要尽快进入冲突或悬念。
- 对白要口语化，适合短视频平台。
- 动作描写要简洁可拍，不写难以落地的抽象心理描写。
- 场景数量要克制，避免单集过度切换。
- 结尾必须服务下一集观看动力。
